# 0.6.0 · 系统方案与小屏对话

发布日期：2026-10-30。旧版基线：v0.5.1（08d4079）。

## 本次变化

- “生成系统方案”放在“分析材料”右侧。已有首轮分析即可使用；范围、定位或对照、针对性行动有有效陈述依据时高亮，不以问答次数判断，也不表示根因已经确认。
- 保留竞争原因、可能共同作用与关系未明的因素。方案先给优先行动，再展开控制、机理措施、验证和固化，不强迫排除到唯一原因。历史方案不能覆盖新证据。
- 默认按现场行动推进，每轮一个有用判断，可合并相关信息。未知转成核查任务；“更多”中可切换深入分析。
- 对话区优先占用高度，输入框外观固定一行，长文本仍完整保留。对话可连续拖宽并覆盖星球，双击分隔线或使用“恢复对话宽度”还原。
- 仅保留深色界面，去掉首页“模型”副标题。保留完整两行作者署名，预留底部间距。
- 前端隐藏本地引导，默认模型对话；未配置时保留草稿并引导设置。后端旧规则能力和旧对话读取仍保留。
- “保存连接”将模型密钥以 Windows 当前用户范围 DPAPI 加密保存，浏览器与桌面入口共用。更换目的地址不误用旧密钥，支持删除；Tavily 仍为独立临时凭据。
- 新会话格式 v3 保存系统方案动作、原待答问题、因素关系与方案依据。支持 v1/v2 导入；生成方案后继续回答原选项，FTA 分支和保存载入保持对应。

## 验证范围

- Python 83 项、JavaScript 会话 11 项测试通过，含加密凭据、地址绑定、请求令牌、证据更正、未知回答、方案非事实、分支及旧存档兼容。
- 使用独立配置目录和合成问答进行 Edge 浏览器验证：保存连接后刷新、方案后继续选项、未发送草稿、单行长文本、输入法回车、覆盖星球拖拽、字号保存及 FTA。测试未使用真实模型密钥、未调用外部模型。
- FTA 回归覆盖节点详情、上一题选择、本题选项、总结、分支、删除恢复、平移、缩放、最大化、紧凑窗口与 395 节点适应全图。
- 正文 16/18/20px 与 5 种实际内容视口共 15 组。回复区实测：1280×620 为 353px，1093×560 为 294px，1024×500 为 234px，800×450 为 184px。输入发送与底部署名均在可见范围。测试模拟内容视口，不等同逐台实测所有物理屏幕和 Windows 缩放组合。
- 正式知识仍为 73 篇、157 节点、294 关系、26 剧本；校验通过，未删除原有知识。
- 已重新编译桌面入口。专业回答质量与真实服务延迟仍需用实际模型和现场情景试用，不把界面及合成测试当作模型准确率。

## 更新与恢复

退出旧桌面版或停止旧启动窗口，再打开新目录的 `隔膜研析.exe` 或 `start-workbench.ps1`。页面刷新后可用新界面；后端新功能需要重启服务。只替换 exe 不会更新完整程序。

GitHub 标签 v0.5.1 与 v0.6.0 分别固定旧版和新版；正常提交保留旧历史，不强推覆盖。需要恢复时，下载 v0.5.1 到独立目录，先停止占用同一端口的新服务，再启动旧版。

本机 `exports/backup-20261030/` 保留旧版完整已跟踪程序归档及本机知识归档；本机案例归档不上传 GitHub。旧浏览器记忆 v5 在正常迁移到 v6 时保留，但“关闭本机记忆”等主动清理操作仍会删除记录。程序没有读取或替用户导出真实浏览器会话；重要调查请主动保存可载入 MD/JSON。

旧版不保证读取新 v3 会话。回退时使用升级前存档；新会话另存保留，不覆盖旧档。代码回退不自动回退本机知识、实际案例或浏览器记忆。加密密钥不随仓库和发布包迁移，换电脑或 Windows 用户需重新配置。
