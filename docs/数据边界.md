# 数据边界

## 程序读取与导出

程序只读取 `knowledge/` 和 `知识图谱/` 索引明确登记的正式正文，以及 `graph/`、指定智能体规则。“知识投递”仅按规定加载 Markdown / TXT，并标记为用户自建、未审核。原始材料没有接入读取、搜索、网页静态访问、模型上下文或导出路径。网页只开放少量界面文件和明确的知识接口，不提供文件夹浏览。

知识包依据 `bundle_manifest.json` 明确清单生成。清单限制目录和后缀，并拒绝符号链接或越界路径。请勿把内部原文或实际生产数据写入知识目录；路径隔离不能代替内容审查。

## 当前问题与模型

未开启联网时，本地规则分析不发送外部请求。当前对话默认保存于浏览器本地存储，刷新后恢复；关闭“本机记忆”会删除这份存储，新对话会清空当前记录。服务端不写对话历史数据库并关闭访问日志。用户导出的对话和问题材料包会包含本次输入，应自行决定保管范围。

模型分析会把用户输入与检索知识发送到所填服务。发送前检查可拦截一些常见联系方式、文件路径、文档名和敏感字段，不能识别所有人名、内部代号、数据组合及配方。用户必须先将问题通用化，并确认可以向该目的服务发送；查看材料包可以核对具体内容。

浏览器保存用户主动保存的接口地址、模型名、协议、知识预算，以及对话宽度和启用记忆时的当前对话。未保存的模型密钥和搜索密钥只保留在页面内存；主动保存的模型密钥由 Windows 当前用户 DPAPI 加密，保存在用户应用目录，不返回明文给前端，也不进入发布文件或会话；环境模型密钥仅按完全匹配的模型接口使用。更换目的地址、协议或模型会清除发送确认。服务端错误不回显供应商的原始响应体。

启用 Tavily 搜索后，只发送公开检索词输入框的内容，不发送整个对话或公司目录。搜索摘录在服务端短时缓存，并可随本机当前对话保存；它们不自动成为正式知识，也不进入通用发布包。正式图谱知识可进入模型材料；自建知识默认只在本机检索，外发需显式选择，默认导出包始终不包含它。

## 能力与限制

这是本机单人工作台，不是面向互联网的生产服务或安全审计工具。它没有用户权限体系、审计数据库或企业数据防泄露系统。不要将本机端口代理到公网。若要团队共享，需要另行设计身份、授权、数据隔离与运维。

原始资料在工作文件夹内保持原样。分享时使用明确生成的发布包，不能把整个工作文件夹压缩发送。公开文献链接可以展示，内部文件标识与数据不进入交付知识。
