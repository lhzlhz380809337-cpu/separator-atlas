# 星图对话

版本 0.5.1。星图就是问题分析首页，原来的独立表单工作台已移除。旧的 #analysis 地址会回到星图。

## 一问一答分析

输入第一个问题后，程序先用一小段限长文字说明整体分析路线，再提出第一个有区分度的问题。后续记录每轮问题、回答、检索依据和阶段。支持直接输入，也支持本地引导的选项按钮。油斑情景内置了发现方式、实物复核、追溯、分布、检测位置、周期和设备检查等分支；其他问题按相关诊断剧本引导。不接模型时，这是一套透明的规则流程，不具备任意语言下的复杂推理能力。

模型对话把本段问答、已采用的交接记录和本轮检索知识交给已配置的模型，通过 agent/dialogue_protocol.md 约束逐步追问、修正与反证。普通回复通常两三句话，只推进一个关键问题，不每轮复述或总结；需要解释时再展开。用户只回答 A/B/C 时，保留前一轮的问题与选项供模型理解。模型可能出错，现场结论仍需验证。

“整理结论”可随时生成详细的阶段性判断与验证任务。结论下方提供“继续深入分析”，点击后从当前 FTA 节点继续追问；也可直接打开 FTA 分析树。证据不足时允许明确写出尚不能确认根因，不把轮数或匹配程度视为确认依据。

## FTA 分析树

FTA 树以每轮“用户输入—助手回答”为节点，并按父子关系横向展开。固定大小的节点卡显示路径状态、本节点问题摘要和上一题选择摘要。单击节点立即弹出详情框：先显示上一题及这次选择的完整文字（例如“A · 实物能确认对应斑点”），再显示本节点的问题和选项。原始分析正文可展开阅读。详情框在小窗口中同样直接显示，正文单独滚动，底部操作保持可见。

正常节点的详情框提供三个操作：

1. **总结此节点之前的内容**：汇总初始问题至本节点的已有问答，不包含其后续或其他分支。
2. **对此问题选择另外选项**：重新回答本节点提出的问题，可以选预设选项或填写另一种现场情况。新答案成为本节点的子分支，原路径保留；程序明确告知模型“这是另一条分析路径”。取消选择会回到原节点详情，成功后显示新节点的详情。
3. **删除此节点及后续**：软删除这个节点及其子树，保留同级的其他来源分支。删除后可以恢复；初始问题作为整棵树的起点保留，删除按钮不可用。

树所在区域是一张独立画布。按住鼠标拖动可以上下左右移动，滚动滚轮以指针位置为中心缩放；“适应全图”会自动缩放并居中整棵树，`＋`、`−` 也可缩放。窗口右上角可最大化和还原。键盘焦点位于画布时，方向键移动，`+`、`-` 缩放，`0` 适应全图。

删除后，原始问答仍保留在树和存档中，删除起点的详情框提供“恢复这段路径”。恢复后重新成为可继续分析的路径。建立新分支、删除或恢复路径后，下一轮会从该路径的原始问答重建结构化分析进度，避免把另一条分支的回答混成同一事实。

节点总结显示在该节点详情框中，不新增问答节点，也不改变当前路径。被软删除的历史节点同样可以总结，便于比较不同假设路径。

每轮先将 A/B/C 对应为具体回答，再依据新信息检索，并沿图谱关联补读最多两层。模型模式可提出最多两项补查请求，程序取得资料后再生成简短回答，通常共两次模型调用；整理结论和交接各一次。计划格式错误或补查请求失败时提示降级；最终回答也失败则保留旧记录。详细规则见 [动态检索与分析进度](动态检索与分析进度.md)。

本机记忆默认开启，在当前浏览器的本地存储中保存当前对话，刷新可恢复。关闭本机记忆会删除这份浏览器记录。新对话会清空当前记录，需要保留时先保存进度。它不等于加密存储或多会话档案。旧版有效的本机问答会在首次恢复时迁移。

## 保存、载入与工程师交接

1. 点击“保存进度”。可直接保存，也可以填写详细的交接记录；已配置模型并允许发送材料时，可点击“用模型整理交接记录”，再核对其中的事实、否定回答和待验证判断。
2. 点击“保存可载入 Markdown”。正文包含完整问答、FTA 当前路径、其他分支、软删除及恢复记录、选项、知识关联、交接记录和未发送草稿；文件末尾嵌入经过字段白名单校验的程序恢复数据。也可以另存 JSON 备份。两者都不保存模型地址、密钥、发送授权或搜索凭证。
3. 下次或另一位工程师在兼容版本工作台点击“载入进度”，选择该 Markdown 或 JSON。先预览，再点击“载入并继续”。当前已有对话时可以先保存备份；格式错误不会替换当前对话。
4. 载入后直接回答最后的问题或补充新观察。接手人的模型配置保持不变，不从文件恢复授权；载入本身不会调用模型或联网搜索。原有知识正文仍由接手人的工作台提供，进度文件不携带整套知识库。
5. 0.5.0 生成的 Markdown 既是阅读版也是恢复文件。旧版仅含阅读正文、没有 `separator-atlas-session` 恢复数据的 Markdown 仍不能载入；“分析材料”JSON 也不是进度文件。

对话较长时，在保存窗口整理并核对交接记录，勾选“我已核对交接记录，后续以它和最后一轮接着分析”。保存后，模型使用交接记录、原始问题和最近一段问答继续，最后一轮的问题与选项会完整保留。早期问答仍在文件和页面中，没有静默删除；但摘要未涵盖的早期细节不会自动进入后续模型上下文，需要补充到交接记录或当前消息。

当前一份进度最多 500 轮、10 MB；FTA 最多 1,000 个节点和 500 条删除记录。单段模型历史最多 50 轮、85,000 字符。页面在约 60,000 字符时提前提示交接，为整理和最后一轮预留空间。达到整理上限时可参照完整问答手工填写记录。交接记录最多 16,000 字符。分段后的对话使用模型模式继续，本地规则模式不能解释任意交接摘要。

模型生成的交接记录可能遗漏或误解，因此不会自动采用为压缩后的上下文，需用户核对后勾选。保存和载入只在本机处理，记录不会自动变成正式案例或知识节点。文件含用户自行输入的内容；分享前自行检查，误粘贴在对话正文中的密钥或内部信息不会因为配置字段已被排除就自动消失。

## 页面和节点

桌面端拖动星图与对话间的分界线即可调整宽度，双击恢复默认。分界线也支持方向键及 Home 键。搜索框固定在星图右上角，随对话宽度移动；狭窄星图区与标题上下错开。小屏采用星图在上、对话在下的布局。

本地节点高亮表示实际进入本轮最终回答材料的片段与关系，不表示读过全文、模型内部注意力或根因已被确认；补查计划阶段的初始候选不累计点亮。新进入的节点短暂增强亮度，实际使用的关联线一起亮起。相关节点的“本轮查阅片段”显示当时片段、查阅理由和关系条件。历史回答可重新点亮对应依据；旧文件没保存的历史片段不会凭空补造。

## 外部知识与流星

在模型设置中填入 Tavily 搜索密钥，或通过 TAVILY_API_KEY 启动环境提供。公开查询接口遵循 [Tavily Search 文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)。搜索密钥和模型密钥彼此独立，页面刷新后临时密钥清空。

展开“外部知识”，开启联网补充，检查公开检索词。程序只把该输入框的检索词发送给 Tavily，不把完整对话、公司目录或内部文件发送给搜索服务。默认检索词由少量通用主题映射生成，可自行调整。一次搜索最多取得五条带 URL 的有效摘录；不读取完整网页，也不声称已核验全文。

联网开启后，新的查询会在提问时自动检索；同一查询短时间复用结果。也可点击“检索并融入星图”。取得新的有效来源时，暖色流星飞入星球并成为当前分析的候选节点。相同来源不反复播放，空结果、连接失败或未配置密钥不播放。关闭动画或系统减少动态效果时直接显示节点。

外部节点与本地节点之间的连接仅表示同轮参考关系，不表示已验证因果。模型对话可使用本轮取得的摘录；本地规则模式只展示来源，不能自动解释其适用性。来源以标题、网址、获取时间与未核验状态显示。

外部结果只进入当前会话，未自动写入正式 Markdown 知识库或通用发布包。浏览器恢复的外部节点是历史摘录；再次发给模型需要重新检索。服务端缓存最多 32 次搜索、每次结果有效 30 分钟，重启后失效。

需要永久沉淀时，将核验后的通用知识写入“知识投递”目录。该目录的原有本地检索、外发选择与导出隔离规则继续有效。
