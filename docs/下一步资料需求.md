# 下一步怎样补知识，而不是继续堆报告

第一版已经能用于学习、梳理候选机制和设计排查。要更贴近现场，优先确认下列通用信息。资料可以在本地阅读学习，不直接纳入可分享知识包；不要求提供真实客户、代号、配方和工艺数值。

| 优先级 | 需要确认的内容 | 能解决的问题 |
|---|---|---|
| 1 | 产品家族与层结构：裸PE、陶瓷、聚合物、混合、叠层、单/双面及前态关系 | 避免跨产品误拼流程、同名“基膜”对象混淆 |
| 1 | 每条实际路线的工序次序、同步/异步、拉伸与萃取先后、各热处理段功能 | 确定知识图谱主干和真实工序接口 |
| 1 | 检测方法定义：单位、方向、仪器原理、干湿、预处理、取样、界面、判读 | 判断透气、粘接、剥离、掉粉等是否可比 |
| 2 | 通用设备功能图与物料/膜材流向；传感器与取样位置的对应 | 将异常位置和时间映射到可检查部位 |
| 2 | 正常/异常问题的通用化描述、支持与反对结果、验证设计及未决项 | 扩充可区分的诊断路径，而不是复制结论 |
| 2 | 卷系谱、分切与检验位置的字段定义，无实际卷号 | 建立前后工序配对、横纵定位和物料滞后判断 |
| 3 | 客户加工环节的通用接口条件与失效类型，不含客户身份 | 细化烘烤、卷叠、热压、注液和受压传输边界 |
| 3 | 现行控制计划与反应计划的字段结构、责任角色及升级逻辑，无限值 | 把确认结果连接到预防、检测、隔离和关闭条件 |

每次以一个具体问题为入口补资料。先问“这份资料能区分哪两个假设”，不能只因报告多就认为知识完整。对缺少证据的结论保留待确认状态；对不同产品或不同年代的控制资料分别建立范围卡。

下一阶段建议先选透气增值、波浪边、掉粉或粘接中的一个主题做完整的通用化试运行。完成问题卡、检索、反证检查、验证设计和人工复核后，再评价智能体真正节省了哪些工作、遗漏了什么。
