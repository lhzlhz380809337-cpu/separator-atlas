## 自动检查结果

- 39 项程序测试通过，覆盖知识结构、预算、检索、图谱正文一致性、目录越界拒绝、星图知识关联、实际材料高亮、知识导出、问答历史、逐步分支、阶段结论、模型请求及外部检索边界。新增网络错误分类、余额及忙碌提示、DeepSeek 完整地址与保活空行解析检查。

- 网络排查：同一 Python 运行时在受限环境访问官方接口得到权限拒绝，在普通运行环境访问官方模型列表得到 HTTP 401（未提供密钥的预期响应），证明网络与 HTTPS 能到达服务。未读取或使用用户 API 密钥，不代表用户账号、模型权限及真实推理已验证。
- 18 个合成评测题中，16 个有明确期望剧本的题全部检索命中；另 2 个保留人工模型行为评审。结果不等于模型专业准确率。

- 原有一个 Windows HTTP 来源拒绝测试曾遇到系统中断连接；随后针对相同测试及全量测试均通过，未屏蔽断言或修改安全校验。

## 页面检查

浏览器实际检查总图默认进入、基膜/涂覆/电芯分区、节点关联高亮、机理—控制点—失控问题阅读、知识库分类与阅读，以及四项共享顶部导航。采用桌面和窄屏尺寸检查导航、图谱与首页对话布局。总图保留全部关系数据，选中节点后突出直接上下游，可用分区和缩放阅读细节。

星图对话保留本地分支追问、对话宽度拖动、知识搜索随边界移动，以及基于实际检索材料的高亮。外部检索和模型接口采用合成响应测试；没有使用真实服务密钥。

## 发布与内容边界

发布工具按明确清单生成独立程序包和知识包，包含图谱 Markdown 与索引。不扫描或打包原始文件夹，不包含自建知识、浏览器对话、密钥和外部会话摘录。图谱的页面和正文不标注内部文件名或原始数据。

## 未覆盖范围

尚未进行真实服务商密钥调用、不同模型专业答案比较、真实生产问题的现场因果验证。通用机理与控制点仍需要按具体材料、工艺路线和质量标准进行专业复核；没有生成新的生产参数限值。程序检查通过不能替代这些工作。
