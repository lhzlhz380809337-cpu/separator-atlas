# 环境与依赖

## 日常使用环境

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 或 Windows 11 | 桌面启动器和 `.cmd` / PowerShell 启动脚本面向 Windows。 |
| Python | 3.10 或更新版本 | 本地知识服务只使用 Python 标准库。建议安装 64 位官方 CPython，并在安装时勾选加入 PATH。 |
| 浏览器 | Microsoft Edge、Google Chrome 或其他现代浏览器 | 桌面版优先使用 Edge，其次 Chrome；都不可用时转到系统默认浏览器。 |
| 本地端口 | 默认 `127.0.0.1:8765` | 只监听本机。端口被占用时可改用其他端口。 |
| 网络 | 本地知识功能不需要网络 | 调用 DeepSeek 等模型接口或 Tavily 搜索时才需要网络。 |

程序运行时没有第三方 Python 包。仓库仍提供标准的 `requirements.txt`，便于自动化工具识别环境；执行安装命令不会额外安装软件：

```powershell
py -3 -m pip install -r requirements.txt
```

## 安装与启动

1. 安装 Python 3.10 或更新版本，在命令行执行 `py -3 --version` 确认可以找到 Python。
2. 下载或解压完整项目，保持目录结构不变。
3. 双击根目录的 `隔膜研析.exe` 使用桌面版；也可以运行 `start-workbench.ps1` 使用浏览器版。
4. 若默认端口被占用，在项目根目录运行：

```powershell
py -3 -X utf8 app/server.py --port 8766 --open
```

然后访问 `http://127.0.0.1:8766/#home`。

## 验证环境

在项目根目录依次运行：

```powershell
py -3 -m unittest discover -s tests -v
py -3 tools/validate.py
py -3 tools/evaluate.py
```

如果电脑只提供 `python` 命令，可以将上述 `py -3` 替换为 `python`。

## 可选开发依赖

日常运行、修改知识 Markdown、修改图谱 JSON 和执行测试均不需要开发依赖。只有重新生成桌面图标时才需要 Pillow：

```powershell
py -3 -m pip install -r requirements-dev.txt
py -3 tools/generate_desktop_icon.py
```

重新编译 `隔膜研析.exe` 还需要 Windows 自带的 .NET Framework C# 编译器。运行 `desktop/build-desktop.ps1` 会自动查找编译器。仓库已经包含编译完成的启动器，普通使用者无需编译。

## 模型服务不是 Python 依赖

DeepSeek 等模型通过 HTTPS 接口连接，不需要安装厂商 SDK。模型地址、模型名称和密钥在页面的“模型设置”中填写。密钥不会写入 `requirements.txt`、Git 仓库或通用知识包。连接失败时应先检查接口地址、模型名称、账户额度、代理和防火墙，而不是重复安装 Python 包。
