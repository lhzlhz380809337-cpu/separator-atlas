# 基膜承载与热稳定


阶段：基膜。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

拉伸强度反映特定方向的拉断能力，穿刺反映规定形状的局部载荷响应，热收缩反映受热后的尺寸变化，电气薄弱点则涉及局部绝缘完整性。它们都受骨架影响，但失效方式不同。平均厚度与平均强度合格也可能漏掉少量薄点、针孔或硬颗粒。


## 由材料变化得到的质量控制点

- 控制局部厚度和薄点，并分方向管理强度、延伸和热收缩

- 统一制样、针头、夹持、加载速率、温度时间及受约束状态，避免跨方法直接比较

- 对可疑颗粒、针孔和划伤采用定位实物复核，联查结构与绝缘完整性


## 节点与概念

- **厚度及均匀性**：需保留横向位置和纵向时间，平均值不能代表局部薄弱。

- **纵横拉伸性能**：强度、模量、伸长和韧性分别评价，保留方向与测试边界。

- **穿刺强度**：指定探针与加载条件下的局部力学响应，不能排除针孔与污染。

- **热收缩**：给定热和约束条件下的尺寸变化，与闭孔、破膜含义不同。

- **局部电弱点**：在规定电测试条件下出现的局部绝缘薄弱，需结合缺陷定位。

- **局部薄点或针孔**：局部承载和隔离能力异常，应与光学亮点进一步区分。


## 关系机理、控制点与失控问题


### 厚度及均匀性 → 透气度（Gurley 时间）

在孔结构相近时，较厚的膜让空气通过的路径更长，透气时间可能增加。若厚度变化同时伴随孔结构改变，就不能只用厚度解释。


质量控制点：

- 控制局部厚度和薄点，并分方向管理强度、延伸和热收缩

- 统一制样、针头、夹持、加载速率、温度时间及受约束状态，避免跨方法直接比较

- 对可疑颗粒、针孔和划伤采用定位实物复核，联查结构与绝缘完整性


控制不好会怎样：透气时间异常或空间分布不均，提示通道改变；不能直接换算电芯内阻。


适用时留意：孔结构及方法可比；核查密封


如何验证这条路径：同位置比较厚度与透气；排除测厚受压差异


### 局部薄点或针孔 → 局部电弱点

局部薄点让绝缘隔离距离和承载余量减小。进一步出现孔洞或受压破损时，可能形成电气薄弱点，平均厚度合格不能覆盖这些小区域。


质量控制点：

- 控制局部厚度和薄点，并分方向管理强度、延伸和热收缩

- 统一制样、针头、夹持、加载速率、温度时间及受约束状态，避免跨方法直接比较

- 对可疑颗粒、针孔和划伤采用定位实物复核，联查结构与绝缘完整性


控制不好会怎样：局部绝缘余量不足，需定位孔洞、硬颗粒或深划伤，而不能依赖平均物性。


适用时留意：区分光学亮点和真实薄点；电测试条件受控


如何验证这条路径：对齐光学缺陷与电弱点位置；检查厚度和形貌


### 厚度及均匀性 → 打皱、中波与塌边

厚区在同一卷径下承受的接触和累积应变不同，薄区更容易出现松弛。横向厚度差随卷层累积，可放大卷形和皱折问题。


质量控制点：

- 控制局部厚度和薄点，并分方向管理强度、延伸和热收缩

- 统一制样、针头、夹持、加载速率、温度时间及受约束状态，避免跨方法直接比较

- 对可疑颗粒、针孔和划伤采用定位实物复核，联查结构与绝缘完整性


控制不好会怎样：皱折影响走膜和涂布接触，可能造成缺涂、叠层与装配不均。


适用时留意：有连续厚度带证据；排除卷芯与辊面原因


如何验证这条路径：比较横向厚度带与缺陷位置；查看随卷径的演变


### 厚度及均匀性 → 横纵向涂布一致性

前态厚薄差会改变涂布间隙、辊面接触或局部走膜状态，进而影响涂层均匀性。涂后总厚度还包含基膜本身，不能把全部差异都归于涂布量。


质量控制点：

- 控制局部厚度和薄点，并分方向管理强度、延伸和热收缩

- 统一制样、针头、夹持、加载速率、温度时间及受约束状态，避免跨方法直接比较

- 对可疑颗粒、针孔和划伤采用定位实物复核，联查结构与绝缘完整性


控制不好会怎样：横纵涂层量和结构差异增大，可能造成局部传输和加工表现不一致。


适用时留意：同设备路线和可比受力状态。


如何验证这条路径：将前态厚度与涂后局部质量、覆盖位置配对。


### 局部薄点或针孔 → 局部绝缘薄弱

局部薄点或针孔减小隔膜的承载和隔离余量，在装配压力或颗粒作用下可能成为更容易破坏的位置。平均厚度合格不能排除它。


质量控制点：

- 控制局部厚度和薄点，并分方向管理强度、延伸和热收缩

- 统一制样、针头、夹持、加载速率、温度时间及受约束状态，避免跨方法直接比较

- 对可疑颗粒、针孔和划伤采用定位实物复核，联查结构与绝缘完整性


控制不好会怎样：孔洞、压伤或覆盖不足使局部更易失去有效隔离。


适用时留意：有局部厚度证据且考虑电极、对位和压力。


如何验证这条路径：定位失效与薄区，比较可比正常区及替代故障路径。


### 局部电弱点 → 局部绝缘薄弱

电气薄弱点提示局部绝缘完整性可能不足，但其在电芯中的作用仍与颗粒、受压及实际接触位置有关，需要定位复核。


质量控制点：

- 控制局部厚度和薄点，并分方向管理强度、延伸和热收缩

- 统一制样、针头、夹持、加载速率、温度时间及受约束状态，避免跨方法直接比较

- 对可疑颗粒、针孔和划伤采用定位实物复核，联查结构与绝缘完整性


控制不好会怎样：孔洞、压伤或覆盖不足使局部更易失去有效隔离。


适用时留意：测法灵敏度、测试面积及样品损伤已核验。


如何验证这条路径：独立显微或电检测确认同位缺陷，核对装配前后状态。


### 穿刺强度 → 局部绝缘薄弱

穿刺结果反映规定针头和载荷下的局部抗破坏能力，可帮助评价机械余量。实际毛刺形状、加载速度和受压环境不同，穿刺合格不能排除局部破损。


质量控制点：

- 统一穿刺针形、加载速率、夹持及干湿状态，保持来料比较有效

- 管理局部薄点和颗粒，并与实际极片毛刺、压力及接触几何对应

- 电芯不良仍需定位破口与导通路径，不以穿刺合格替代绝缘完整性检查


控制不好会怎样：孔洞、压伤或覆盖不足使局部更易失去有效隔离。


适用时留意：探头、速度、方向、膜态和取样设计可比。


如何验证这条路径：结合分布、局部缺陷和加工负荷，不能只看均值。


### 热收缩 → 受热后膜完整性

基膜受热收缩会减少相对极片的覆盖；涂层能否约束这种收缩取决于连接与受力。热完整性需同时看覆盖、孔洞和结构连续性。


质量控制点：

- 控制局部厚度和薄点，并分方向管理强度、延伸和热收缩

- 统一制样、针头、夹持、加载速率、温度时间及受约束状态，避免跨方法直接比较

- 对可疑颗粒、针孔和划伤采用定位实物复核，联查结构与绝缘完整性


控制不好会怎样：受热后出现覆盖丧失、孔洞或破裂，隔离功能可能无法维持。


适用时留意：温度、时间、方向、干湿与约束条件明确。


如何验证这条路径：结合热后完整性、界面与实际装配边界做可比验证。


## 还应追溯哪些上游

- 计量与混合供料 → 厚度及均匀性：单位时间供给的聚合物量发生变化，在幅宽和速度相近时，单位面积获得的固体量也会变化，形成纵向厚度或克重波动。 详见 [[投料与两相体系]]。

- 熔体过滤 → 厚度及均匀性：过滤阻力升高或换网扰动会改变熔体压力与流量。当供料控制补偿不足时，模头输出不稳会转化为铸片厚度波动。 详见 [[挤出塑化与熔体过滤]]。

- 流延成型 → 厚度及均匀性：模头间隙和流道分配决定横向供料，牵引速度决定这些物料被摊开的程度。局部唇口积料和接触不均会留下厚薄条带。 详见 [[铸片冷却与相分离]]。

- 纵横取向 → 纵横拉伸性能：取向使微纤沿载荷方向更有效地承载，因此会改变纵横拉伸强度及延伸。若取向伴随薄区或骨架损伤，强度并不会持续提高。 详见 [[双向拉伸与孔骨架]]。

- 微孔承载骨架 → 穿刺强度：穿刺载荷需要周围骨架共同分担。纤维连接、局部厚度和缺陷决定应力能否扩散，少量薄弱点可能先于平均结构破坏。 详见 [[双向拉伸与孔骨架]]。

- 微孔承载骨架 → 纵横拉伸性能：拉伸时载荷沿骨架传递。骨架连续性、连接点和方向分布共同决定断裂位置及强度，孔隙较多并不自动等于强度不足。 详见 [[双向拉伸与孔骨架]]。

- 残余应力与回复倾向 → 热收缩：残留应力使拉直的分子链在再次受热时倾向回到更松弛的状态，表现为膜尺寸减小。外部约束、温度和保温时间会改变测得的收缩量。 详见 [[萃取后横拉、干燥与热定型]]。

- 黑点与异物 → 局部电弱点：黑点若含金属或硬颗粒，可能导电或在压紧时损伤薄膜；普通有色聚合物颗粒的风险机制不同。要先识别成分、形状和是否贯穿。 详见 [[挤出塑化与熔体过滤]]。

- 分切边缘损伤 → 纵横拉伸性能：边部裂口和损伤会集中拉伸应力，载荷尚未达到主体膜的承载能力时，就可能从切边起裂，降低测得的强度。 详见 [[一次分切、边缘与洁净]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
