# 涂覆前态、润湿与涂布均匀性


阶段：涂覆。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

浆料需要先铺展并接触膜面，再由供料与设备几何形成规定湿层。残油、褶皱、表面处理差异会使局部接触和润湿不同；浆料流变、间隙和速度波动又会改变涂布量。缺涂、条纹、总厚度和涂层克重必须结合前态膜对应位置分析，不能互相替代。


## 由材料变化得到的质量控制点

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


## 节点与概念

- **前态膜**：进入本次涂覆的膜，可能是原始基膜或已涂覆中间体。

- **前态膜表面状态**：表面能、污染及既有涂层共同决定浆料接触。

- **涂布转移**：由供液、接触几何及运行状态共同决定湿膜分布。

- **涂层覆盖形态**：连续或离散覆盖、局部厚薄与开放区域。

- **横纵向涂布一致性**：涂层量与覆盖在空间和时间上的一致程度。

- **涂层面密度**：单位面积涂层质量，需与前态膜正确对应。

- **涂层厚度**：厚度受测量压力、粗糙度与孔隙影响。

- **条纹与漏涂**：局部供液、铺展或后续干燥形成的覆盖异常。


## 关系机理、控制点与失控问题


### 前态膜 → 前态膜表面状态

前态膜的材料、涂层、残油和表面处理共同决定表面状态。裸PE与已有涂层中间体的润湿和结合方式可能完全不同。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：润湿或表面清洁不足会形成缩边、缺涂和界面结合不良。


适用时留意：明确前态膜层次及面向


如何验证这条路径：表面形貌；润湿对照


### 前态膜表面状态 → 涂布转移

浆料只有充分铺展并接触表面才能形成连续湿层。表面能不匹配或局部油污会导致缩边、露底和界面接触不足。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：湿层无法稳定形成，出现供料不连续、边部覆盖或均匀性问题。


适用时留意：同浆料同方法比较


如何验证这条路径：湿膜观察；表面污染检查


### 涂布转移 → 涂层覆盖形态

供料、间隙或辊接触决定湿层能否覆盖目标区域。张力、润湿和边部形貌不稳时，即使平均涂布量足够也会留下缺涂。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：局部露底、缺涂或孔口覆盖过度，可能分别影响支撑、界面和离子入口。


适用时留意：涂布方式已知


如何验证这条路径：湿膜与干膜对应；覆盖面积定义


### 涂布转移 → 横纵向涂布一致性

涂布过程把浆料流量转换为单位面积湿层。供料脉动、间隙偏差、辊速或张力不稳，会形成横向或纵向涂布量差异。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：横纵涂层量和结构差异增大，可能造成局部传输和加工表现不一致。


适用时留意：固定浆料与前态膜


如何验证这条路径：横向位置图；周期性缺陷图


### 横纵向涂布一致性 → 涂层面密度

局部湿层量及固含不同，干燥后留下的固体质量也不同。整幅平均克重可能掩盖细条纹和边部异常。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：干涂层量不足或过多，可能影响覆盖、连接和孔道；平均值可能漏掉局部异常。


适用时留意：前态膜取样准确对应


如何验证这条路径：横向极差；纵向一致性


### 涂层面密度 → 涂层厚度

同样干涂层质量在不同堆积密度和孔隙率下会形成不同厚度；同样厚度也可能含不同固体量。克重与厚度需成对解释。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：局部厚度和压缩性差异，可能影响卷形、装配压力及传输距离。


适用时留意：组成与孔隙状态可比


如何验证这条路径：质量厚度联合测量；截面观察


### 涂层覆盖形态 → 涂层贯穿孔道

覆盖孔口的涂层可能让离子改走涂层间隙，也可能堵住部分入口。影响取决于覆盖方式、涂层自身孔隙及受压后的形态。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：有效液体通路缩窄或不均，即使厚度克重正常，透气和湿态电阻也可能变差。


适用时留意：区分表面空白与实际连通孔


如何验证这条路径：表面/截面联看；湿态电阻


### 涂层覆盖形态 → 实际浸润状态

连续覆盖、岛状覆盖及局部缺涂会形成不同的液体入口分布。若覆盖后孔口被堵，局部浸润可能变慢或不均。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：局部干区或困气使离子通路不连续，形成电流与反应分布不均。


适用时留意：明确方向和材料结构


如何验证这条路径：分别测试两方向；控制前态膜


### 涂层厚度 → 隔膜有效离子电阻

在结构和润湿状态相近时，较厚涂层增加离子需要经过的路径。若同时改变孔隙或接触状态，就需要拆分这些影响。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：离子传输或其他电芯阻抗贡献增大，需分解来源后才能归因。


适用时留意：结构和浸润状态可比


如何验证这条路径：厚度压力基准；有效电阻


### 涂层覆盖形态 → 局部绝缘薄弱

对于依靠涂层提供局部耐热或机械支撑的产品，缺涂使该处支撑减弱；若基膜仍完整，缺涂本身并不等于立即短路。


质量控制点：

- 核对前态层结构、涂布面、方向和卷段，检查残油、皱折及表面润湿状态

- 按实际涂布方式管理供料、间隙或辊接触、线速比、张力和边缘覆盖

- 对涂前涂后厚度、干涂层克重、覆盖率及横纵分布进行配对管理，识别细条纹和局部缺涂


控制不好会怎样：孔洞、压伤或覆盖不足使局部更易失去有效隔离。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


## 还应追溯哪些上游

- 浆料使用稳定性 → 横纵向涂布一致性：沉降、絮凝或局部浓缩使供到涂头的浆料随时间或位置改变，形成涂布量和表面形貌差异，平均固含可能仍在范围内。 详见 [[涂覆投料、分散与浆料状态]]。

- 浆料流变 → 涂布转移：浆料在供液、间隙和铺展时经历不同剪切，流变决定它能否连续供给、铺平并保持形状。单一转速测得的粘度不能完整代表涂布状态。 详见 [[涂覆投料、分散与浆料状态]]。

- 浆料气泡 → 条纹与漏涂：气泡占据应由浆料覆盖的位置，破裂后留下针孔、缺涂或拖尾条纹。烘干后气泡本身消失，缺陷却可能保留下来。 详见 [[过滤、消泡与涂层异物]]。

- 颗粒团聚 → 条纹与漏涂：大团聚体可阻塞局部涂布通道，或被拖动形成长条痕，也可能直接形成凸点。异常常随涂头位置或颗粒通过而呈现不同形态。 详见 [[过滤、消泡与涂层异物]]。

- 功能聚合物 → 涂层覆盖形态：聚合物颗粒、岛状层或连续层的成膜方式不同，会得到不同覆盖形态。相同涂覆量不能推定孔口被覆盖的程度相同。 详见 [[涂覆投料、分散与浆料状态]]。

- 分切 → 前态膜：分切后的基膜把厚度、孔结构、表面、边部和卷内应力一起交给涂覆工序。涂覆前态验收需要继承这些状态及对应卷段，已有涂层中间体要单独识别。 详见 [[一次分切、边缘与洁净]]。

- 厚度及均匀性 → 横纵向涂布一致性：前态厚薄差会改变涂布间隙、辊面接触或局部走膜状态，进而影响涂层均匀性。涂后总厚度还包含基膜本身，不能把全部差异都归于涂布量。 详见 [[基膜承载与热稳定]]。

- 打皱、中波与塌边 → 涂层覆盖形态：褶皱和松弛使膜面与涂头或涂辊的距离、接触发生变化，局部可能缺涂或堆料。先确认皱折是在涂布前存在还是烘干后产生。 详见 [[收卷、松弛与卷形]]。

- 残油 → 前态膜表面状态：残油改变基膜表面能并可能形成隔离层，使水性浆料难以铺展或与基膜结合。是否出现缺涂取决于油的分布、性质和浆料体系。 详见 [[萃取置换与残油]]。

- 凝胶点与鱼眼 → 涂层覆盖形态：凝胶点或鱼眼让膜面局部高度、润湿及孔结构不同，可能造成涂层局部露底或堆积。应将涂前点位与涂后覆盖对应。 详见 [[挤出塑化与熔体过滤]]。

- 铸片厚边 → 横纵向涂布一致性：未去除或未稳定的厚边会使涂布接触与边缘供料条件不同，造成边部涂层偏厚、缺涂或卷形异常；需确认实际裁边位置。 详见 [[铸片冷却与相分离]]。

- 条状亮油斑 → 涂层覆盖形态：若条斑处有油性残留，浆料可能沿该条带缩退或结合不足，出现条状缺涂。要先证明位置对应及残留成分，避免把相似条纹误接成因果。 详见 [[油斑、CCD与污染路径]]。

- 暗油斑 → 横纵向涂布一致性：暗斑若来自残油或积液，会影响润湿；若来自皱折或压印，会改变局部涂布接触。这些不同路径都可能造成涂层量不均，需要实物区分。 详见 [[油斑、CCD与污染路径]]。

- 横排点状亮斑 → 涂层覆盖形态：点斑区域若存在污染，会使浆料在相应点位不能正常覆盖。若只是照明或算法伪影，则不应推断存在实际缺涂风险。 详见 [[油斑、CCD与污染路径]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
