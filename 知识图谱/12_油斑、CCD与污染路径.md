# 油斑、CCD与污染路径


阶段：基膜。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

CCD中的亮暗来自透光、散射和表面形貌变化，能识别异常外观，但不能单凭亮暗证明化学成分为白油。先将图像坐标与实物对应，再区分残油、混合液夹带、辊面转印、烘箱滴落、压痕或算法误判。缺陷纵向节距、横向位置和首次出现工序比一个缺陷名称更有定位价值。


## 由材料变化得到的质量控制点

- 锁定CCD规则与照明状态，保存原图、卷长和横向位置，用对应实物及正常对照确认异常

- 按缺陷节距与实际线速换算时间，再与辊周长、转速和间歇动作比对，考虑工序间拉伸比和打滑

- 分别管理萃取残油、刮液带液、烘房补排风、链夹润滑和辊面清洁，依据确认路径进行针对性调整


## 节点与概念

- **油斑**：疑似局部残油或相关外观异常，需位置与成分确认。

- **条状亮油斑**：CCD识别的条状亮斑形态；需确认实物、成分及纵向周期。

- **暗油斑**：CCD识别的暗斑形态；残油、积液转移或压痕等都需实物区分。

- **横排点状亮斑**：同一横向排布的点状亮斑，可用于追溯滴落、夹持或间歇接触事件。

- **链夹痕与针板痕**：夹持边部的压力、磨损或错位留下的痕迹，需检查损伤及有效幅宽。


## 关系机理、控制点与失控问题


### 油斑 → 浸液后离子传输阻力

若油斑处确有油性物质占据孔道或妨碍电解液进入，局部离子通路会变差。若只是压印或光学伪影，则应按实物结构另行判断。


质量控制点：

- 锁定CCD规则与照明状态，保存原图、卷长和横向位置，用对应实物及正常对照确认异常

- 按缺陷节距与实际线速换算时间，再与辊周长、转速和间歇动作比对，考虑工序间拉伸比和打滑

- 分别管理萃取残油、刮液带液、烘房补排风、链夹润滑和辊面清洁，依据确认路径进行针对性调整


控制不好会怎样：局部离子传输阻力增加或不均，进入电芯后可能加大极化。


适用时留意：油斑性质已确认；后续浸润及电芯条件明确


如何验证这条路径：做局部结构与残留对照；必要时匹配应用试验


### 条状亮油斑 → 涂层覆盖形态

若条斑处有油性残留，浆料可能沿该条带缩退或结合不足，出现条状缺涂。要先证明位置对应及残留成分，避免把相似条纹误接成因果。


质量控制点：

- 锁定CCD规则与照明状态，保存原图、卷长和横向位置，用对应实物及正常对照确认异常

- 按缺陷节距与实际线速换算时间，再与辊周长、转速和间歇动作比对，考虑工序间拉伸比和打滑

- 分别管理萃取残油、刮液带液、烘房补排风、链夹润滑和辊面清洁，依据确认路径进行针对性调整


控制不好会怎样：局部露底、缺涂或孔口覆盖过度，可能分别影响支撑、界面和离子入口。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 暗油斑 → 横纵向涂布一致性

暗斑若来自残油或积液，会影响润湿；若来自皱折或压印，会改变局部涂布接触。这些不同路径都可能造成涂层量不均，需要实物区分。


质量控制点：

- 锁定CCD规则与照明状态，保存原图、卷长和横向位置，用对应实物及正常对照确认异常

- 按缺陷节距与实际线速换算时间，再与辊周长、转速和间歇动作比对，考虑工序间拉伸比和打滑

- 分别管理萃取残油、刮液带液、烘房补排风、链夹润滑和辊面清洁，依据确认路径进行针对性调整


控制不好会怎样：横纵涂层量和结构差异增大，可能造成局部传输和加工表现不一致。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 横排点状亮斑 → 涂层覆盖形态

点斑区域若存在污染，会使浆料在相应点位不能正常覆盖。若只是照明或算法伪影，则不应推断存在实际缺涂风险。

如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 链夹痕与针板痕 → 切边与局部损伤

夹持痕位于最终保留边部时，可能影响涂布接触和边缘平整；若按实际裁边方案完全移除，就不应继续外推到成品。

- 锁定CCD规则与照明状态，保存原图、卷长和横向位置，用对应实物及正常对照确认异常

控制不好会怎样：边裂、缺口、掉粉或折边可能影响走膜对齐和有效覆盖。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


## 还应追溯哪些上游

- 残油 → 油斑：残油在局部富集时可能改变透光与散射，呈现油斑外观。总残油高不一定形成可见斑点，可见斑点也不一定是残油造成。 详见 [[萃取置换与残油]]。

- 流延成型 → 油斑：铸片两相分布不均可能让局部富油区偏大，增加后续萃取负担并遗留斑点。只有确认局部残油后才能将外观油斑归于该路径。 详见 [[铸片冷却与相分离]]。

- 萃取混合液夹带 → 暗油斑：夹带的混合液若在表面局部聚集，挥发后可能留下白油或其他残留，形成暗斑；也可能只是液体造成的暂时光学差异。 详见 [[萃取置换与残油]]。

- 萃取后横拉 → 条状亮油斑：受热使已有油性残留迁移，或污染接触件把残留带到膜上，可能形成亮条斑。烘房负压和补排风异常是候选诱因，形态本身不能证明油的来源。 详见 [[萃取后横拉、干燥与热定型]]。

- 萃取后横拉 → 横排点状亮斑：平台积油、废膜附着物、冷凝滴落或周期接触事件，可能在相近时刻影响多个横向位置，形成横排点斑。需要用设备位置和实物对应验证。 详见 [[萃取后横拉、干燥与热定型]]。

- 萃取后横拉 → 链夹痕与针板痕：链夹磨损、夹持不稳或针板位置异常，会在边部集中压力并留下痕迹；严重时引起拉裂、有效幅宽损失或后续边部覆盖问题。 详见 [[萃取后横拉、干燥与热定型]]。

- 收卷 → 暗油斑：收卷皱折或压印改变局部散射，可能在后续CCD中被分为暗斑或暗条纹。未发现油性成分时，应按卷形或接触损伤排查。 详见 [[收卷、松弛与卷形]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
