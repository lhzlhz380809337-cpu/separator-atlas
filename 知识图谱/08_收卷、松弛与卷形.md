# 收卷、松弛与卷形


阶段：基膜。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

收卷将平整薄膜变成多层圆柱，内外层受到不同张力和径向压力。厚度横向差、张力锥度或压辊接触不均会使卷内应力分布不均，产生松紧差、滑移、皱折和端面不齐。下游看到的条纹有时是上游应力与接触痕迹的延迟显现，不一定是涂布时新产生的。


## 由材料变化得到的质量控制点

- 按卷径管理张力锥度和接触压力，控制启停与速度变化的瞬态响应

- 检查摆辊动作、辊面清洁及干结硬物，保持辊系平行和纠偏稳定

- 检查卷硬度横向分布、端面齐整、错层和窜卷，按统一条件进行时效或调湿后复验


## 节点与概念

- **收卷**：张力、压合、卷芯和来膜状态共同决定层间状态及卷内应力。

- **熟化与状态调节**：按实际目的定义条件与时间；不默认能修复膜面缺陷。

- **打皱、中波与塌边**：需区分自由来膜状态和卷绕、接触引入的变形。

- **弧度与跑偏倾向**：需按自由膜及规定受力状态测量，不能只由端面外观判定。

- **层间滑移与端面不齐**：可能与层间接触、摩擦、纠偏及卷芯有关，不能只归因张力不足。


## 关系机理、控制点与失控问题


### 收卷 → 打皱、中波与塌边

收卷张力或卷内压力不均，使部分区域被拉紧、部分区域松弛，层间不能均匀贴合，可能形成皱折及后续展开不平。


质量控制点：

- 按卷径管理张力锥度和接触压力，控制启停与速度变化的瞬态响应

- 检查摆辊动作、辊面清洁及干结硬物，保持辊系平行和纠偏稳定

- 检查卷硬度横向分布、端面齐整、错层和窜卷，按统一条件进行时效或调湿后复验


控制不好会怎样：皱折影响走膜和涂布接触，可能造成缺涂、叠层与装配不均。


适用时留意：区分收卷前已有变形和新增缺陷


如何验证这条路径：比较收卷前与放卷样；记录缺陷随卷径及位置变化


### 收卷 → 层间滑移与端面不齐

层间摩擦不足、张力锥度不合适或端面受扰，会使已卷绕的膜层相对移动，形成错层、窜卷或端面不齐。


质量控制点：

- 按卷径管理张力锥度和接触压力，控制启停与速度变化的瞬态响应

- 检查摆辊动作、辊面清洁及干结硬物，保持辊系平行和纠偏稳定

- 检查卷硬度横向分布、端面齐整、错层和窜卷，按统一条件进行时效或调湿后复验


控制不好会怎样：层间滑移、窜卷或端面不齐可能造成边部损伤和放卷异常。


适用时留意：同材料表面和卷芯条件


如何验证这条路径：检查卷内位置与端面演变；核查纠偏及层间状态


### 熟化与状态调节 → 尺寸与幅宽稳定性

放置和调湿使部分应力及吸附状态逐渐变化，测试时的尺寸也可能随之改变。因此必须统一存放时间和环境，区分短时变化与稳定状态。


质量控制点：

- 按卷径管理张力锥度和接触压力，控制启停与速度变化的瞬态响应

- 检查摆辊动作、辊面清洁及干结硬物，保持辊系平行和纠偏稳定

- 检查卷硬度横向分布、端面齐整、错层和窜卷，按统一条件进行时效或调湿后复验


控制不好会怎样：幅宽、侧弯或松弛变化可能导致后道对齐、接触和有效覆盖不稳。


适用时留意：熟化目的、包装、环境明确


如何验证这条路径：匹配卷段做时间对照；排除搬运和环境变化


### 收卷 → 划伤与压印

摆辊或其他辊面上的干结硬物会反复挤压膜面，形成周期压印或划伤。辊面清洁、动作状态与实物表面检查需相互对应。


质量控制点：

- 按卷径管理张力锥度和接触压力，控制启停与速度变化的瞬态响应

- 检查摆辊动作、辊面清洁及干结硬物，保持辊系平行和纠偏稳定

- 检查卷硬度横向分布、端面齐整、错层和窜卷，按统一条件进行时效或调湿后复验


控制不好会怎样：深划伤会削弱骨架，压印则可能改变外观和涂布接触；须分别确认。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 收卷 → 暗油斑

收卷皱折或压印改变局部散射，可能在后续CCD中被分为暗斑或暗条纹。未发现油性成分时，应按卷形或接触损伤排查。


质量控制点：

- 按卷径管理张力锥度和接触压力，控制启停与速度变化的瞬态响应

- 检查摆辊动作、辊面清洁及干结硬物，保持辊系平行和纠偏稳定

- 检查卷硬度横向分布、端面齐整、错层和窜卷，按统一条件进行时效或调湿后复验


控制不好会怎样：暗斑会影响外观判级；其后道影响取决于残油、夹带液还是皱折压印的实物性质。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 打皱、中波与塌边 → 涂层覆盖形态

褶皱和松弛使膜面与涂头或涂辊的距离、接触发生变化，局部可能缺涂或堆料。先确认皱折是在涂布前存在还是烘干后产生。


质量控制点：

- 按卷径管理张力锥度和接触压力，控制启停与速度变化的瞬态响应

- 检查摆辊动作、辊面清洁及干结硬物，保持辊系平行和纠偏稳定

- 检查卷硬度横向分布、端面齐整、错层和窜卷，按统一条件进行时效或调湿后复验


控制不好会怎样：局部露底、缺涂或孔口覆盖过度，可能分别影响支撑、界面和离子入口。


适用时留意：缺陷在涂布前已存在且位置能追溯。


如何验证这条路径：对照涂前走膜状态和涂后缺陷坐标。


### 打皱、中波与塌边 → 可用容量

皱折可能造成局部叠层、接触差或覆盖偏移，使部分区域的电流和浸润分布不均，影响可用容量；要与电极本身缺陷区分。


质量控制点：

- 按卷径管理张力锥度和接触压力，控制启停与速度变化的瞬态响应

- 检查摆辊动作、辊面清洁及干结硬物，保持辊系平行和纠偏稳定

- 检查卷硬度横向分布、端面齐整、错层和窜卷，按统一条件进行时效或调湿后复验


控制不好会怎样：规定测试条件下可用容量下降或一致性变差，需区分传输受限与活性材料损失。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


## 还应追溯哪些上游

- 厚度及均匀性 → 打皱、中波与塌边：厚区在同一卷径下承受的接触和累积应变不同，薄区更容易出现松弛。横向厚度差随卷层累积，可放大卷形和皱折问题。 详见 [[基膜承载与热稳定]]。

- 分切 → 弧度与跑偏倾向：分切各分条受力或边缘损伤不对称时，条带两侧的伸长不同，展开后可能侧向弯曲。母卷已有应力差也会在分切释放后显现。 详见 [[一次分切、边缘与洁净]]。

- 残余应力与回复倾向 → 打皱、中波与塌边：沿宽度或厚度分布不均的应力，在放松或加热后释放程度不同，局部膜长不一致会形成皱折和松弛区域。 详见 [[萃取后横拉、干燥与热定型]]。

- 双拉段横向拉伸 → 打皱、中波与塌边：横向受热、夹持或拉伸不同步，会造成各区域伸长不一致，放松后形成皱折或松弛。单纯调整收卷张力可能只能暂时遮盖上游问题。 详见 [[双向拉伸与孔骨架]]。

- 一牵引 → 打皱、中波与塌边：牵引张力偏低或响应迟缓使膜段松弛，辊速差又会让局部多拉或少拉。长度不一致在后段累积后表现为皱折或松弛区。 详见 [[一牵引与含油膜输送]]。

- 一牵引 → 弧度与跑偏倾向：纠偏不稳或辊系不平行会使膜两侧受力不同，产生跑偏、边部不齐或释放后侧弯。要区分走膜轨迹偏移与材料自身侧弯。 详见 [[一牵引与含油膜输送]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
