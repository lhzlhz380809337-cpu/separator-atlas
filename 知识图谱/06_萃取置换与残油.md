# 萃取置换与残油


阶段：基膜。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

萃取剂进入含油膜后，白油向周围液体扩散，再由循环和补液带走。换液能力不足或浴液含油过高，会削弱传质推动力；接触时间和温度也会改变移除速度。萃取后孔内仍有液体，要经过刮液和干燥才能形成实际使用的干态孔道。


## 由材料变化得到的质量控制点

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


## 节点与概念

- **萃取剂**：用于移除稀释剂；介质性质及回用状态影响传质和后续挥发。

- **萃取**：通过溶解与传质移除稀释剂，不能简化为过滤杂质。

- **萃取剂回收与回用**：回用液组成及波动属于萃取诊断条件，应核查适用质量项目。

- **残油**：稀释剂残留需用适用方法定量，不能由外观干燥推断。

- **萃取混合液夹带**：孔内和表面携带的萃取剂与白油混合液影响干燥负荷及污染路径。


## 关系机理、控制点与失控问题


### 萃取剂 → 萃取

萃取剂进入凝胶膜并溶解或置换白油。对两者的相容性、润湿和扩散能力不同，会改变白油被移除的效率。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：萃取有效推动力或换液能力不足，造成残油和空间分布异常。


适用时留意：使用批准介质与实际回用状态


如何验证这条路径：检查有效组成及残油趋势；对照接触和停留条件


### 萃取剂回收与回用 → 萃取

回用液带回的白油和杂质会改变萃取剂的有效组成。即使温度和线速没变，槽液与膜内白油的浓度差也可能减小。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：萃取有效推动力或换液能力不足，造成残油和空间分布异常。


适用时留意：明确取样点及检测覆盖范围


如何验证这条路径：比较回用液趋势与产出时延；检查未覆盖污染可能性


### 萃取 → 残油

白油需要从膜内扩散到槽液，再被循环和补液带走。传质推动力、时间或换液不足，会留下更高或更不均匀的残油。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：残油可能占据孔道、影响表面润湿，并在局部形成可见斑点。


适用时留意：残油方法适用且位置匹配


如何验证这条路径：同时测异常及邻近正常区；核查入口含油状态


### 萃取 → 孔道连通性

移除白油让原有富油区域成为可使用的孔隙，但是否贯通仍取决于前面形成的骨架。萃取不完全会占据或堵住部分通道。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：有效贯通通道减少，透气时间和湿态电阻可能升高。


适用时留意：区分残留影响与结构收缩


如何验证这条路径：比较残油、尺寸和透气组合；必要时观察前后结构


### 残油 → 透气度（Gurley 时间）

残油占据部分孔容或附着在孔喉，会改变空气通路及表面状态。局部残油还可能被平均取样稀释，需与缺陷位置对应。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：透气时间异常或空间分布不均，提示通道改变；不能直接换算电芯内阻。


适用时留意：残留定量可靠且同位置


如何验证这条路径：测异常与正常区残油；复核厚度及其他孔道变化


### 残油 → 油斑

残油在局部富集时可能改变透光与散射，呈现油斑外观。总残油高不一定形成可见斑点，可见斑点也不一定是残油造成。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：油斑或类似光学缺陷增多，影响外观判级；实物污染还可能引出缺涂和传输异常。


适用时留意：确认局部缺陷与样品位置


如何验证这条路径：对缺陷区做适用成分检验；与邻近正常区比较


### 萃取 → 萃取混合液夹带

刮液不足、靠距或穿膜不合适，会让更多混合液随膜进入烘箱。流量或线速变化也会改变带液量和后续蒸发负荷。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：增加干燥负荷，并可能经残留、冷凝或接触转移形成新的斑点。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 萃取混合液夹带 → 暗油斑

夹带的混合液若在表面局部聚集，挥发后可能留下白油或其他残留，形成暗斑；也可能只是液体造成的暂时光学差异。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：暗斑会影响外观判级；其后道影响取决于残油、夹带液还是皱折压印的实物性质。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 萃取混合液夹带 → 干燥

进入干燥区的液体增加后，需要更多蒸发和排风能力。能力不足会残留，气流或冷表面条件不合适还可能发生冷凝和回落。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：蒸发与排风负荷失配，可能残留、冷凝或因过热改变膜态。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 残油 → 前态膜表面状态

残油改变基膜表面能并可能形成隔离层，使水性浆料难以铺展或与基膜结合。是否出现缺涂取决于油的分布、性质和浆料体系。


质量控制点：

- 按检测定义控制各槽有效萃取剂浓度与含油量，维持合理梯度，不能把含油浓度和溶剂浓度混称为浓度

- 控制槽温、进液量、循环流量、停留时间与回用液状态

- 控制穿膜路径、辊速差及刮液辊靠距和受力，减少带液且避免擦伤变形

- 分开检测残油与残溶剂，对异常区和正常区进行配对取样


控制不好会怎样：润湿或表面清洁不足会形成缩边、缺涂和界面结合不良。


适用时留意：残留物与涂覆体系存在相应界面作用。


如何验证这条路径：分别核查表面、整体残留、润湿及同源粘接。


### 残油 → 可用容量

残油若妨碍电解液浸润或占据孔道，可使局部反应利用不充分，降低规定工况下的可用容量。容量变化不能反过来单独证明残油超标。

## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
