# 过滤、消泡与涂层异物


阶段：涂覆。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

浆料中的大团聚体可能卡在涂布间隙或形成凸点，气泡则会在涂布或干燥后留下空洞。过滤能够截留一部分颗粒，但不能代替分散；泵入口漏气、压降和回流也可能引入气泡。异物还可能在干燥、分切、包装时二次带入。


## 由材料变化得到的质量控制点

- 匹配过滤精度与正常颗粒尺寸，管理压差、密封、换滤和下游洁净

- 保持供液、泵入口、回流和脱泡稳定，避免吸气或再卷气

- 控制静电、设备磨屑、清洁残留和环境落尘，对异常颗粒识别成分与尺寸


## 节点与概念

- **过滤与脱泡**：控制截留范围内的物质及气泡，需分别验证效果。

- **浆料气泡**：可参与局部供液中断或成膜缺口。

- **颗粒团聚**：区别于一次颗粒的聚集体，可改变表面与流动。

- **膜面异物**：需按形状、组成、位置及来源分类评价。

- **静电状态**：影响微粒吸附的因素之一，不能替代洁净度。


## 关系机理、控制点与失控问题


### 过滤与脱泡 → 颗粒团聚

过滤主要截留较大颗粒或团聚体。网孔、压差、密封和团聚体变形能力决定截留效果，过滤不能替代前端分散。


质量控制点：

- 匹配过滤精度与正常颗粒尺寸，管理压差、密封、换滤和下游洁净

- 保持供液、泵入口、回流和脱泡稳定，避免吸气或再卷气

- 控制静电、设备磨屑、清洁残留和环境落尘，对异常颗粒识别成分与尺寸


控制不好会怎样：大团聚体可能堵涂头、形成凸点或拖出条纹。


适用时留意：过滤介质与流量明确


如何验证这条路径：过滤前后粒径；压差和滤渣


### 过滤与脱泡 → 浆料气泡

过滤压降和换滤操作可能造成气体释放或卷入，入口供液不足也会诱发吸气。气泡应结合过滤器、泵和回路一起排查。


质量控制点：

- 匹配过滤精度与正常颗粒尺寸，管理压差、密封、换滤和下游洁净

- 保持供液、泵入口、回流和脱泡稳定，避免吸气或再卷气

- 控制静电、设备磨屑、清洁残留和环境落尘，对异常颗粒识别成分与尺寸


控制不好会怎样：气泡可能在干燥后留下孔洞、露底或条纹。


适用时留意：脱泡方法与浆料相容


如何验证这条路径：脱泡前后气泡观察；湿膜缺陷


### 浆料气泡 → 条纹与漏涂

气泡占据应由浆料覆盖的位置，破裂后留下针孔、缺涂或拖尾条纹。烘干后气泡本身消失，缺陷却可能保留下来。


质量控制点：

- 匹配过滤精度与正常颗粒尺寸，管理压差、密封、换滤和下游洁净

- 保持供液、泵入口、回流和脱泡稳定，避免吸气或再卷气

- 控制静电、设备磨屑、清洁残留和环境落尘，对异常颗粒识别成分与尺寸


控制不好会怎样：连续或间歇条纹可能造成缺涂或局部堆料，并影响外观判级。


适用时留意：排除颗粒与表面污染


如何验证这条路径：缺口形貌；脱泡对照


### 颗粒团聚 → 条纹与漏涂

大团聚体可阻塞局部涂布通道，或被拖动形成长条痕，也可能直接形成凸点。异常常随涂头位置或颗粒通过而呈现不同形态。


质量控制点：

- 匹配过滤精度与正常颗粒尺寸，管理压差、密封、换滤和下游洁净

- 保持供液、泵入口、回流和脱泡稳定，避免吸气或再卷气

- 控制静电、设备磨屑、清洁残留和环境落尘，对异常颗粒识别成分与尺寸


控制不好会怎样：连续或间歇条纹可能造成缺涂或局部堆料，并影响外观判级。


适用时留意：与涂布几何及缺陷位置匹配


如何验证这条路径：缺陷成分形貌；过滤前后对照


### 静电状态 → 膜面异物

带电薄膜会吸附悬浮粉尘并使碎屑更难脱离。静电是异物附着的促进因素，异物本身仍需追溯产生源和成分。


质量控制点：

- 匹配过滤精度与正常颗粒尺寸，管理压差、密封、换滤和下游洁净

- 保持供液、泵入口、回流和脱泡稳定，避免吸气或再卷气

- 控制静电、设备磨屑、清洁残留和环境落尘，对异常颗粒识别成分与尺寸


控制不好会怎样：异物可能形成孔道堵塞、压点或导电路径，风险随成分与尺寸而变化。


适用时留意：存在可接近颗粒；测量距离一致


如何验证这条路径：静电与膜面颗粒联测


### 膜面异物 → 局部绝缘薄弱

金属颗粒可能导电，硬颗粒可能集中压力并压伤隔膜，普通软粉末则可能主要影响孔道和接触。成分、尺寸与位置决定风险路径。


质量控制点：

- 匹配过滤精度与正常颗粒尺寸，管理压差、密封、换滤和下游洁净

- 保持供液、泵入口、回流和脱泡稳定，避免吸气或再卷气

- 控制静电、设备磨屑、清洁残留和环境落尘，对异常颗粒识别成分与尺寸


控制不好会怎样：孔洞、压伤或覆盖不足使局部更易失去有效隔离。


适用时留意：形貌位置组成与受载明确


如何验证这条路径：异物对应局部损伤；受控正常对照


### 膜面异物 → 局部绝缘薄弱

涂覆或后加工引入的异物可能造成压点、孔道堵塞或导电路径。必须确认颗粒成分、尺寸及装配位置，不能把所有黑点都判为金属。


质量控制点：

- 匹配过滤精度与正常颗粒尺寸，管理压差、密封、换滤和下游洁净

- 保持供液、泵入口、回流和脱泡稳定，避免吸气或再卷气

- 控制静电、设备磨屑、清洁残留和环境落尘，对异常颗粒识别成分与尺寸


控制不好会怎样：孔洞、压伤或覆盖不足使局部更易失去有效隔离。


适用时留意：颗粒材质、大小、位置和电芯工况需确认。


如何验证这条路径：保持原态失效证据并分析成分、位置及工序来源。


## 还应追溯哪些上游

- 分散状态 → 颗粒团聚：未充分润湿或拆散的颗粒会以团聚体存在；分散后若体系不稳定，还会再次聚集。因此过滤前的大颗粒不一定全来自原料。 详见 [[涂覆投料、分散与浆料状态]]。

- 涂覆分切 → 膜面异物：切割可能产生膜屑、涂层粉末或刀具磨屑。没有及时收集的碎屑会再次附着到膜上，并随卷绕进入后续加工。 详见 [[涂覆后加工、包装与热稳定]]。

- 涂层掉粉 → 膜面异物：掉落粉末如果留在膜面，会变成后续可见颗粒或局部压点。陶瓷或聚合物粉末与导电金属碎屑的失效路径不同。 详见 [[涂层界面、内聚与粘接]]。

- 包装与储运 → 膜面异物：包装材料、洁净度和搬运会影响成品表面是否新增颗粒。封装前合格不能排除包装操作中的二次污染。 详见 [[涂覆后加工、包装与热稳定]]。

- 膜屑与粉尘附着 → 膜面异物：基膜上的膜屑、粉尘或刀屑进入涂覆后，可能被涂层包住，形成颗粒凸点或黑点。涂覆发现颗粒并不说明颗粒一定在涂覆产生。 详见 [[一次分切、边缘与洁净]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
