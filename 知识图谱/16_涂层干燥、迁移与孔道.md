# 涂层干燥、迁移与孔道


阶段：涂覆。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

干燥去掉液体并使颗粒和聚合物形成稳定涂层。表面蒸发、内部液体补给和组分扩散速度不一致时，粘结剂分布、孔口和界面可能一起改变。干燥太慢可能有残留，过快可能形成表层富集或应力；具体变化取决于涂层组成和结构，不能只用烘箱最高温度解释。


## 由材料变化得到的质量控制点

- 控制分区温度、实际膜温、风量、湿度或溶剂负荷与停留时间，防止入口骤干和局部过热

- 联查干燥前后透气增值、孔口形貌、剥离断口及残留，不以克重厚度正常排除孔道异常

- 分开控制水分、工艺溶剂和基膜残留，规定取样密封、储存与复验条件


## 节点与概念

- **涂层干燥**：液体移除与结构形成，同时带来膜热历史。

- **组分厚向分布**：液相迁移、扩散与固定化竞争后的组分位置。

- **涂层贯穿孔道**：开放且连通的跨层路径，区别于总孔隙数量。

- **水分与挥发物残留**：残留水平须由适配检测及一致取样确认。


## 关系机理、控制点与失控问题


### 涂层干燥 → 组分厚向分布

干燥时液体流向蒸发表面，粘结剂随液体移动，同时自身又向浓度较低处扩散。两种速度不匹配时，最终分布可能不均。


质量控制点：

- 控制分区温度、实际膜温、风量、湿度或溶剂负荷与停留时间，防止入口骤干和局部过热

- 联查干燥前后透气增值、孔口形貌、剥离断口及残留，不以克重厚度正常排除孔道异常

- 分开控制水分、工艺溶剂和基膜残留，规定取样密封、储存与复验条件


控制不好会怎样：粘结剂在界面或孔口分布不均，可能同时出现剥离与透气增值异常。


适用时留意：仅为待验证机理；不能直接移植电极结论


如何验证这条路径：成分厚向分析；失效位置对照


### 组分厚向分布 → 涂层与基膜界面

粘结剂若从界面附近迁走，该处连接可能不足；局部富集也可能改变断裂位置。是否发生需结合断口和组分分布验证。


质量控制点：

- 控制分区温度、实际膜温、风量、湿度或溶剂负荷与停留时间，防止入口骤干和局部过热

- 联查干燥前后透气增值、孔口形貌、剥离断口及残留，不以克重厚度正常排除孔道异常

- 分开控制水分、工艺溶剂和基膜残留，规定取样密封、储存与复验条件


控制不好会怎样：涂层从基膜表面脱离，湿态或受热后可能失去局部约束。


适用时留意：证明实际发生迁移


如何验证这条路径：成分与剥离互证；同残留不同历程


### 组分厚向分布 → 涂层贯穿孔道

迁移后的粘结剂可能聚集在表面、颗粒间或基膜孔口，缩窄传输通道。厚度和克重未变时，透气与湿态电阻仍可能改变。


质量控制点：

- 控制分区温度、实际膜温、风量、湿度或溶剂负荷与停留时间，防止入口骤干和局部过热

- 联查干燥前后透气增值、孔口形貌、剥离断口及残留，不以克重厚度正常排除孔道异常

- 分开控制水分、工艺溶剂和基膜残留，规定取样密封、储存与复验条件


控制不好会怎样：有效液体通路缩窄或不均，即使厚度克重正常，透气和湿态电阻也可能变差。


适用时留意：材料分辨能力足够


如何验证这条路径：截面与透气；湿态传输


### 涂层干燥 → 水分与挥发物残留

干燥把水或工艺溶剂从涂层内部带走，膜面干燥并不保证内部残留已达要求。气流负荷、停留时间和后续再吸湿都影响最终结果。


质量控制点：

- 控制分区温度、实际膜温、风量、湿度或溶剂负荷与停留时间，防止入口骤干和局部过热

- 联查干燥前后透气增值、孔口形貌、剥离断口及残留，不以克重厚度正常排除孔道异常

- 分开控制水分、工艺溶剂和基膜残留，规定取样密封、储存与复验条件


控制不好会怎样：水分或工艺溶剂残留可能带入后续工序，影响界面反应及储存一致性。


适用时留意：测量目标物与方法适配


如何验证这条路径：密封取样；残留与膜温对照


### 涂层干燥 → 热尺寸稳定性

涂覆烘箱的热量会作用到PE骨架，使其应力释放或继续受拉。局部受热和张力不同，可改变尺寸稳定性和卷后平整度。


质量控制点：

- 控制分区温度、实际膜温、风量、湿度或溶剂负荷与停留时间，防止入口骤干和局部过热

- 联查干燥前后透气增值、孔口形貌、剥离断口及残留，不以克重厚度正常排除孔道异常

- 分开控制水分、工艺溶剂和基膜残留，规定取样密封、储存与复验条件


控制不好会怎样：涂层不能有效约束基膜，复合膜受热尺寸或平整度可能不稳定。


适用时留意：前态膜与累计热历史明确


如何验证这条路径：热收缩方向性；受约束对照


### 涂层贯穿孔道 → 实际浸润状态

涂层的贯通孔、孔喉和表面润湿影响电解液穿过涂层的速度。表面很容易铺展不等于厚度方向全部浸透。


质量控制点：

- 控制分区温度、实际膜温、风量、湿度或溶剂负荷与停留时间，防止入口骤干和局部过热

- 联查干燥前后透气增值、孔口形貌、剥离断口及残留，不以克重厚度正常排除孔道异常

- 分开控制水分、工艺溶剂和基膜残留，规定取样密封、储存与复验条件


控制不好会怎样：局部干区或困气使离子通路不连续，形成电流与反应分布不均。


适用时留意：液体表面作用与装配压力明确


如何验证这条路径：面内/贯穿分测；实际液体测试


### 涂层贯穿孔道 → 隔膜有效离子电阻

涂层形成额外的离子传输路径，孔喉狭窄、堵塞或曲折程度增加时，湿态电阻可能上升；连续且充分润湿的孔道有助于维持传输。


质量控制点：

- 控制分区温度、实际膜温、风量、湿度或溶剂负荷与停留时间，防止入口骤干和局部过热

- 联查干燥前后透气增值、孔口形貌、剥离断口及残留，不以克重厚度正常排除孔道异常

- 分开控制水分、工艺溶剂和基膜残留，规定取样密封、储存与复验条件


控制不好会怎样：离子传输或其他电芯阻抗贡献增大，需分解来源后才能归因。


适用时留意：相同电解液温度与厚度基准


如何验证这条路径：独立隔膜阻抗；孔结构对照


## 还应追溯哪些上游

- 涂层覆盖形态 → 涂层贯穿孔道：覆盖孔口的涂层可能让离子改走涂层间隙，也可能堵住部分入口。影响取决于覆盖方式、涂层自身孔隙及受压后的形态。 详见 [[涂覆前态、润湿与涂布均匀性]]。

- 包装与储运 → 水分与挥发物残留：包装的防潮性和密封状态影响膜与空气的水分交换。干燥后暴露时间过长或密封失效，可能使水分重新升高。 详见 [[涂覆后加工、包装与热稳定]]。

- 电芯烘烤 → 水分与挥发物残留：烘烤可移除部分水和挥发性物质，但效果受扩散距离、真空、温度和时间限制。烘后转运暴露又可能引入吸湿。 详见 [[电芯装配、热压与烘烤]]。

- 聚合物湿态变化 → 涂层贯穿孔道：溶胀使聚合物占据的空间变化，可能缩窄孔喉或改变液体通道。吸液量增加并不保证贯穿方向电阻下降。 详见 [[注液、浸润与电解液相容性]]。

- 残溶 → 水分与挥发物残留：基膜带入的溶剂可能与涂层水分或工艺溶剂共同构成最终残留。检测总挥发物异常时，要按组分区分来源，不能都归为涂覆烘干不足。 详见 [[萃取后横拉、干燥与热定型]]。

- 透气度（Gurley 时间） → 涂层贯穿孔道：基膜透气时间提供涂前空气通路的参照，可用于识别涂后变化来自基膜还是涂层。它不是涂层孔径的直接测量值，必须同位置配对。 详见 [[基膜孔结构与离子传输]]。

- 孔径及孔径分布 → 涂层贯穿孔道：基膜孔口尺寸与表面形态影响浆料进入孔内的深度。过多渗入或在孔口形成覆盖会改变复合膜传输通路，作用取决于颗粒与孔喉尺寸及润湿。 详见 [[双向拉伸与孔骨架]]。

- 残余应力与回复倾向 → 涂层干燥：基膜的回缩应力在涂覆烘箱中可能释放，使幅宽和平整度发生变化；烘箱张力又会约束或重新拉伸它。因此需把前态热历史与涂覆干燥一起追踪。 详见 [[萃取后横拉、干燥与热定型]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
