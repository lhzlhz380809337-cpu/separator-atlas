# 注液、浸润与电解液相容性


阶段：电芯。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

电解液从表面进入隔膜并充满贯通孔道，才形成连续的离子运输路径。表面接触角小不代表厚度方向已经浸透，气体滞留也会使局部干区持续存在。电解液还会让某些聚合物溶胀、软化或改变界面，从而影响孔道和粘接。


## 由材料变化得到的质量控制点

- 固定电解液体系、温度、接触时间与受压状态，区分面内扩散与贯穿浸润

- 管理注液、真空、静置或加压程序，结合实际层间间隙判断局部干区

- 检查浸泡后尺寸、质量、涂层脱落及湿态电阻，区分吸液、溶胀和溶出


## 节点与概念

- **注液与静置**：液体进入和气体排出共同决定实际浸润。

- **电解液体系**：电导率、粘度、表面相容与溶胀作用依体系而异。

- **实际浸润状态**：在装配条件下的面内和贯穿浸润程度。

- **聚合物湿态变化**：电解液引起的溶胀、塑化及界面响应。


## 关系机理、控制点与失控问题


### 注液与静置 → 实际浸润状态

注液程序决定液体进入层间并排出气体的机会。注液量足够也可能因困气、堆叠压紧或静置不足而留下局部干区。


质量控制点：

- 固定电解液体系、温度、接触时间与受压状态，区分面内扩散与贯穿浸润

- 管理注液、真空、静置或加压程序，结合实际层间间隙判断局部干区

- 检查浸泡后尺寸、质量、涂层脱落及湿态电阻，区分吸液、溶胀和溶出


控制不好会怎样：局部干区或困气使离子通路不连续，形成电流与反应分布不均。


适用时留意：注液路径液体及静置明确


如何验证这条路径：质量与浸润观察；阻抗随时间


### 电解液体系 → 实际浸润状态

电解液粘度、表面张力及与材料的相互作用会改变铺展与入孔行为。某种电解液下的好润湿不能自动外推到其他体系。


质量控制点：

- 固定电解液体系、温度、接触时间与受压状态，区分面内扩散与贯穿浸润

- 管理注液、真空、静置或加压程序，结合实际层间间隙判断局部干区

- 检查浸泡后尺寸、质量、涂层脱落及湿态电阻，区分吸液、溶胀和溶出


控制不好会怎样：局部干区或困气使离子通路不连续，形成电流与反应分布不均。


适用时留意：配方温度与预处理明确


如何验证这条路径：实际液体接触角；动态浸润


### 电解液体系 → 聚合物湿态变化

电解液进入聚合物后可能增加链间距离，使涂层溶胀或软化。程度取决于材料和溶剂相容性、时间及温度。


质量控制点：

- 固定电解液体系、温度、接触时间与受压状态，区分面内扩散与贯穿浸润

- 管理注液、真空、静置或加压程序，结合实际层间间隙判断局部干区

- 检查浸泡后尺寸、质量、涂层脱落及湿态电阻，区分吸液、溶胀和溶出


控制不好会怎样：聚合物尺寸或力学状态变化，可能影响孔道、界面和湿态稳定性。


适用时留意：材料与液体特定；时间温度明确


如何验证这条路径：尺寸/形貌；干湿力学对照


### 聚合物湿态变化 → 涂层与基膜界面

涂层吸液溶胀后，界面应力和粘结剂状态会改变，可能增大接触，也可能削弱结合。必须检查湿态断口而不只看干态剥离。


质量控制点：

- 固定电解液体系、温度、接触时间与受压状态，区分面内扩散与贯穿浸润

- 管理注液、真空、静置或加压程序，结合实际层间间隙判断局部干区

- 检查浸泡后尺寸、质量、涂层脱落及湿态电阻，区分吸液、溶胀和溶出


控制不好会怎样：涂层从基膜表面脱离，湿态或受热后可能失去局部约束。


适用时留意：浸液历程一致


如何验证这条路径：湿态剥离；失效位置


### 聚合物湿态变化 → 涂层贯穿孔道

溶胀使聚合物占据的空间变化，可能缩窄孔喉或改变液体通道。吸液量增加并不保证贯穿方向电阻下降。


质量控制点：

- 固定电解液体系、温度、接触时间与受压状态，区分面内扩散与贯穿浸润

- 管理注液、真空、静置或加压程序，结合实际层间间隙判断局部干区

- 检查浸泡后尺寸、质量、涂层脱落及湿态电阻，区分吸液、溶胀和溶出


控制不好会怎样：有效液体通路缩窄或不均，即使厚度克重正常，透气和湿态电阻也可能变差。


适用时留意：排除未浸润与测试几何


如何验证这条路径：湿态厚度；受压电阻


### 实际浸润状态 → 隔膜有效离子电阻

未浸透区域缺少连续液体通路，电流被迫通过其余区域，局部离子传输阻力和不均匀性增加。


质量控制点：

- 固定电解液体系、温度、接触时间与受压状态，区分面内扩散与贯穿浸润

- 管理注液、真空、静置或加压程序，结合实际层间间隙判断局部干区

- 检查浸泡后尺寸、质量、涂层脱落及湿态电阻，区分吸液、溶胀和溶出


控制不好会怎样：离子传输或其他电芯阻抗贡献增大，需分解来源后才能归因。


适用时留意：排除离子旁路和接触问题


如何验证这条路径：阻抗随浸润时间；面积控制


### 电解液体系 → 隔膜有效离子电阻

电解液本身的离子电导率和粘度决定液体通路的传输能力。相同隔膜在不同电解液和温度下可得到不同电阻。


质量控制点：

- 固定电解液体系、温度、接触时间与受压状态，区分面内扩散与贯穿浸润

- 管理注液、真空、静置或加压程序，结合实际层间间隙判断局部干区

- 检查浸泡后尺寸、质量、涂层脱落及湿态电阻，区分吸液、溶胀和溶出


控制不好会怎样：离子传输或其他电芯阻抗贡献增大，需分解来源后才能归因。


适用时留意：电解液与温度固定


如何验证这条路径：液体本体电导；隔膜电阻


## 还应追溯哪些上游

- 涂层贯穿孔道 → 实际浸润状态：涂层的贯通孔、孔喉和表面润湿影响电解液穿过涂层的速度。表面很容易铺展不等于厚度方向全部浸透。 详见 [[涂层干燥、迁移与孔道]]。

- 涂层覆盖形态 → 实际浸润状态：连续覆盖、岛状覆盖及局部缺涂会形成不同的液体入口分布。若覆盖后孔口被堵，局部浸润可能变慢或不均。 详见 [[涂覆前态、润湿与涂布均匀性]]。

- 孔道连通性 → 实际浸润状态：贯通孔提供电解液从表面进入内部的连续路径。孔道断续、孔喉堵塞或困气会使贯穿浸润变慢，即使表面很快被润湿。 详见 [[基膜孔结构与离子传输]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
