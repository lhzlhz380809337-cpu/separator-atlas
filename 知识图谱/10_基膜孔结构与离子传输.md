# 基膜孔结构与离子传输


阶段：基膜。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

电解液填充连通孔后才形成主要离子通路。孔隙率说明空隙占比，孔喉大小、连通性和曲折程度则决定通路是否畅通。空气透过时间、干态孔隙率和浸液后的电阻观察的是不同侧面；一个合格值不能代替其他指标，更不能直接等同整电芯内阻。


## 由材料变化得到的质量控制点

- 分别管理厚度、克重、孔隙率、孔径分布及贯通孔，按结构异常追溯冷却、拉伸和萃取

- 统一透气测试面积、压差、温湿度与取样方向，比较同卷同位置的涂前涂后数据

- 湿态电阻控制电解液、温度、压紧量和充分浸润条件，排除夹具与接触电阻


## 节点与概念

- **孔隙率**：孔体积比例；不同测试方法各有假设，不能替代孔道连通性。

- **孔道连通性**：孔道贯通及连接状态，单张表面图不能代表膜厚方向连通。

- **有效通道曲折程度**：传输路径绕行与约束；解释离子传输时需匹配电解液与浸润状态。

- **透气度（Gurley 时间）**：固定方法下通过时间较长表示空气阻力较大，不等同于离子电导。

- **浸液后离子传输阻力**：需指定电解液、浸润和夹持条件，不直接等同于整电芯内阻。

- **克重与面密度**：单位面积质量；解释时需区分聚合物、残留与孔空间贡献。


## 关系机理、控制点与失控问题


### 孔道连通性 → 透气度（Gurley 时间）

只有贯穿膜两面的孔道才能形成有效透气通路。盲孔、断续孔或局部堵塞会减少可通气截面，使透气时间增大。


质量控制点：

- 分别管理厚度、克重、孔隙率、孔径分布及贯通孔，按结构异常追溯冷却、拉伸和萃取

- 统一透气测试面积、压差、温湿度与取样方向，比较同卷同位置的涂前涂后数据

- 湿态电阻控制电解液、温度、压紧量和充分浸润条件，排除夹具与接触电阻


控制不好会怎样：透气时间异常或空间分布不均，提示通道改变；不能直接换算电芯内阻。


适用时留意：膜厚、残留和方法可比


如何验证这条路径：对比表面与截面证据；检查残留及测试漏气


### 有效通道曲折程度 → 浸液后离子传输阻力

离子沿充满电解液的孔道迁移，路径越绕，穿过同样膜厚需要走得越远。曲折度增加通常会提高有效离子传输阻力。


质量控制点：

- 分别管理厚度、克重、孔隙率、孔径分布及贯通孔，按结构异常追溯冷却、拉伸和萃取

- 统一透气测试面积、压差、温湿度与取样方向，比较同卷同位置的涂前涂后数据

- 湿态电阻控制电解液、温度、压紧量和充分浸润条件，排除夹具与接触电阻


控制不好会怎样：局部离子传输阻力增加或不均，进入电芯后可能加大极化。


适用时留意：固定电解液、温度和夹持条件


如何验证这条路径：比较浸液阻抗与充分浸润状态；检查样品厚度


### 孔隙率 → 浸液后离子传输阻力

充分润湿时，孔隙提供可供离子迁移的液体空间。但新增孔隙若不贯通，或在受压后关闭，就不能按孔隙率直接推算电阻降低。


质量控制点：

- 分别管理厚度、克重、孔隙率、孔径分布及贯通孔，按结构异常追溯冷却、拉伸和萃取

- 统一透气测试面积、压差、温湿度与取样方向，比较同卷同位置的涂前涂后数据

- 湿态电阻控制电解液、温度、压紧量和充分浸润条件，排除夹具与接触电阻


控制不好会怎样：局部离子传输阻力增加或不均，进入电芯后可能加大极化。


适用时留意：孔隙方法一致；浸润与压缩状态已知


如何验证这条路径：比较孔隙率与浸液阻抗；检查连通和残留


### 克重与面密度 → 孔隙率

对成分已知且没有额外残留的裸基膜，克重除以厚度反映表观密度，可与实质密度比较估算孔隙率。涂层、残油或测厚压缩会破坏这种简单换算。


质量控制点：

- 仅在明确材料密度、层结构及残留状态时使用克重和厚度估算孔隙率

- 统一称重面积与测厚接触压力，避免涂层质量或压缩误差混入

- 对估算异常用合适的独立孔隙或结构方法复核，再追溯原料配比与成孔过程


控制不好会怎样：孔隙率偏移或横向不均，可能影响吸液、传输及承载的一致性。


适用时留意：不用于未知复合结构；保留方法假设


如何验证这条路径：核对厚度与克重同位置；检查残留和密度定义


### 孔道连通性 → 浸液后离子传输阻力

连通孔形成从一面到另一面的电解液通路。连通性变差会减少有效通道，即使总孔隙率相同，湿态电阻仍可能上升。


质量控制点：

- 分别管理厚度、克重、孔隙率、孔径分布及贯通孔，按结构异常追溯冷却、拉伸和萃取

- 统一透气测试面积、压差、温湿度与取样方向，比较同卷同位置的涂前涂后数据

- 湿态电阻控制电解液、温度、压紧量和充分浸润条件，排除夹具与接触电阻


控制不好会怎样：局部离子传输阻力增加或不均，进入电芯后可能加大极化。


适用时留意：电解液与浸润、夹持条件一致


如何验证这条路径：比较浸润完成前后阻抗；核查残留及截面证据


### 透气度（Gurley 时间） → 涂层贯穿孔道

基膜透气时间提供涂前空气通路的参照，可用于识别涂后变化来自基膜还是涂层。它不是涂层孔径的直接测量值，必须同位置配对。


质量控制点：

- 保留同卷段同横向位置的基膜透气参照，避免跨产品或不连续工序比较

- 涂前涂后使用一致的测试条件，同时记录涂层量、覆盖与厚度

- 透气增值异常时检查孔口形貌、干燥与浆料状态，再以湿态电阻验证传输影响


控制不好会怎样：有效液体通路缩窄或不均，即使厚度克重正常，透气和湿态电阻也可能变差。


适用时留意：配对卷段、同测法、同条件，明确前态层结构。


如何验证这条路径：保留前后原值、分布、位置和差值，不只比较增值。


### 浸液后离子传输阻力 → 隔膜有效离子电阻

隔膜湿态离子电阻参与电芯离子传输阻力，但整电芯还包含电极、界面和接触贡献。要通过匹配电解液及压力的对照拆分贡献。


质量控制点：

- 分别管理厚度、克重、孔隙率、孔径分布及贯通孔，按结构异常追溯冷却、拉伸和萃取

- 统一透气测试面积、压差、温湿度与取样方向，比较同卷同位置的涂前涂后数据

- 湿态电阻控制电解液、温度、压紧量和充分浸润条件，排除夹具与接触电阻


控制不好会怎样：离子传输或其他电芯阻抗贡献增大，需分解来源后才能归因。


适用时留意：电解液、压力、温度、浸润和测量模型可比。


如何验证这条路径：膜内电阻测量与电芯交叉配对联合核验。


### 孔道连通性 → 实际浸润状态

贯通孔提供电解液从表面进入内部的连续路径。孔道断续、孔喉堵塞或困气会使贯穿浸润变慢，即使表面很快被润湿。


质量控制点：

- 分别管理厚度、克重、孔隙率、孔径分布及贯通孔，按结构异常追溯冷却、拉伸和萃取

- 统一透气测试面积、压差、温湿度与取样方向，比较同卷同位置的涂前涂后数据

- 湿态电阻控制电解液、温度、压紧量和充分浸润条件，排除夹具与接触电阻


控制不好会怎样：局部干区或困气使离子通路不连续，形成电流与反应分布不均。


适用时留意：电解液体系、压力、温度与表面状态明确。


如何验证这条路径：分别考察表面铺展、厚度方向浸润和时间演化。


## 还应追溯哪些上游

- 萃取 → 孔道连通性：移除白油让原有富油区域成为可使用的孔隙，但是否贯通仍取决于前面形成的骨架。萃取不完全会占据或堵住部分通道。 详见 [[萃取置换与残油]]。

- 厚度及均匀性 → 透气度（Gurley 时间）：在孔结构相近时，较厚的膜让空气通过的路径更长，透气时间可能增加。若厚度变化同时伴随孔结构改变，就不能只用厚度解释。 详见 [[基膜承载与热稳定]]。

- 孔径及孔径分布 → 透气度（Gurley 时间）：空气通过时受到孔喉与孔壁阻碍，孔喉变窄或有效孔数减少往往延长透气时间。平均孔径相同的膜也可能因分布和贯通程度不同而透气不同。 详见 [[双向拉伸与孔骨架]]。

- 残油 → 透气度（Gurley 时间）：残油占据部分孔容或附着在孔喉，会改变空气通路及表面状态。局部残油还可能被平均取样稀释，需与缺陷位置对应。 详见 [[萃取置换与残油]]。

- 油斑 → 浸液后离子传输阻力：若油斑处确有油性物质占据孔道或妨碍电解液进入，局部离子通路会变差。若只是压印或光学伪影，则应按实物结构另行判断。 详见 [[油斑、CCD与污染路径]]。

- 计量与混合供料 → 孔隙率：PE与白油的比例决定可形成骨架和富油区域的相对数量，影响成孔空间的起点。最终孔隙率还受结晶、拉伸、萃取与回缩共同影响。 详见 [[投料与两相体系]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
