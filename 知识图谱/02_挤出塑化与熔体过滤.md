# 挤出塑化与熔体过滤


阶段：基膜。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

高温和剪切使树脂在白油中充分溶胀、塑化并均匀分散。温度低、剪切或停留不足会留下未塑化颗粒；过热或滞留又可能产生降解、炭化物。过滤截留颗粒，同时给熔体流动带来阻力，因此要把洁净度和供料稳定性一起管住。


## 由材料变化得到的质量控制点

- 控制各区实际温度及偏差、剪切负荷与停留时间，清除易滞留物料的死角

- 稳定连续供料，联动看熔体压力、过滤前后压差与产出波动

- 按颗粒截留要求管理过滤精度、密封及换网时机，防止旁路和破网


## 节点与概念

- **混炼挤出**：使材料混合并形成可流动的加工体系；热、剪切、时间与组成共同作用。

- **熔体过滤**：降低适用尺寸与性质的颗粒，同时改变流动阻力；压差需结合流量与黏度解释。

- **熔体与凝胶均匀性**：组成、温度与分散的空间均匀程度，压力稳定不能单独证明。

- **黑点与异物**：外观名称不能判定成分；先区分聚合物降解物、金属及其他污染。

- **凝胶点与鱼眼**：未塑化或局部聚集的物料形成结构不均，需与降解物及外来颗粒区分。


## 关系机理、控制点与失控问题


### 混炼挤出 → 熔体与凝胶均匀性

挤出依靠热量和剪切把树脂充分塑化并与白油混匀。塑化不足保留颗粒，过热滞留则可能降解，两个方向都能破坏均匀性。


质量控制点：

- 控制各区实际温度及偏差、剪切负荷与停留时间，清除易滞留物料的死角

- 稳定连续供料，联动看熔体压力、过滤前后压差与产出波动

- 按颗粒截留要求管理过滤精度、密封及换网时机，防止旁路和破网


控制不好会怎样：塑化或混合不均会传递为鱼眼、局部厚度及成孔差异。


适用时留意：材料与产量可比；实际反馈有效


如何验证这条路径：检查实际温度及压力分布；观察过程样中的未均匀区域


### 熔体与凝胶均匀性 → 黑点与异物

未混匀区域可能留下凝胶或未塑化点；若伴随滞留降解，才可能出现炭化黑点。黑点也可能来自外来颗粒，不能只按颜色认定来源。


质量控制点：

- 控制各区实际温度及偏差、剪切负荷与停留时间，清除易滞留物料的死角

- 稳定连续供料，联动看熔体压力、过滤前后压差与产出波动

- 按颗粒截留要求管理过滤精度、密封及换网时机，防止旁路和破网


控制不好会怎样：黑点可能影响覆盖；含金属或硬质颗粒时还可能带来局部隔离风险。


适用时留意：先做缺陷形貌和成分确认


如何验证这条路径：比较黑点与树脂或外来物成分；检查停机再开机及缺陷聚集关系


### 熔体过滤 → 黑点与异物

过滤截留超过有效通道尺寸的颗粒。滤网破损、旁路或下游再污染会让颗粒重新进入膜，较软的凝胶也可能变形通过。


质量控制点：

- 控制各区实际温度及偏差、剪切负荷与停留时间，清除易滞留物料的死角

- 稳定连续供料，联动看熔体压力、过滤前后压差与产出波动

- 按颗粒截留要求管理过滤精度、密封及换网时机，防止旁路和破网


控制不好会怎样：黑点可能影响覆盖；含金属或硬质颗粒时还可能带来局部隔离风险。


适用时留意：确认过滤系统完整和工作状态


如何验证这条路径：检查滤后样缺陷；核对更换前后趋势及缺陷成分


### 熔体过滤 → 厚度及均匀性

过滤阻力升高或换网扰动会改变熔体压力与流量。当供料控制补偿不足时，模头输出不稳会转化为铸片厚度波动。


质量控制点：

- 控制各区实际温度及偏差、剪切负荷与停留时间，清除易滞留物料的死角

- 稳定连续供料，联动看熔体压力、过滤前后压差与产出波动

- 按颗粒截留要求管理过滤精度、密封及换网时机，防止旁路和破网


控制不好会怎样：厚薄条带和薄点会影响后续拉伸、收卷、涂布及局部隔离余量。


适用时留意：相同速度与物料条件或完成分层比较


如何验证这条路径：比较过滤压差与产出厚度时序；排除传感器偏移


### 黑点与异物 → 局部电弱点

黑点若含金属或硬颗粒，可能导电或在压紧时损伤薄膜；普通有色聚合物颗粒的风险机制不同。要先识别成分、形状和是否贯穿。


质量控制点：

- 控制各区实际温度及偏差、剪切负荷与停留时间，清除易滞留物料的死角

- 稳定连续供料，联动看熔体压力、过滤前后压差与产出波动

- 按颗粒截留要求管理过滤精度、密封及换网时机，防止旁路和破网


控制不好会怎样：局部绝缘余量不足，需定位孔洞、硬颗粒或深划伤，而不能依赖平均物性。


适用时留意：异物成分及形态已确认


如何验证这条路径：对齐电测试和缺陷位置；区分金属与非金属


### 混炼挤出 → 凝胶点与鱼眼

温度、剪切或停留不足时，局部树脂不能充分塑化，可能留下凝胶点或鱼眼。过热滞留造成的降解物则应另行辨认。


质量控制点：

- 控制各区实际温度及偏差、剪切负荷与停留时间，清除易滞留物料的死角

- 稳定连续供料，联动看熔体压力、过滤前后压差与产出波动

- 按颗粒截留要求管理过滤精度、密封及换网时机，防止旁路和破网


控制不好会怎样：凝胶点和鱼眼造成局部结构或高度异常，可能导致涂布露底或薄弱区域。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 混炼挤出 → 黑点与异物

物料在死角长时间受热，或局部温度失控时，可能降解并形成黑点或黄变。外来异物也是黑点来源，必须结合成分和出现时序区分。

### 凝胶点与鱼眼 → 涂层覆盖形态

凝胶点或鱼眼让膜面局部高度、润湿及孔结构不同，可能造成涂层局部露底或堆积。应将涂前点位与涂后覆盖对应。

控制不好会怎样：局部露底、缺涂或孔口覆盖过度，可能分别影响支撑、界面和离子入口。

## 还应追溯哪些上游

- 白油与稀释剂 → 熔体与凝胶均匀性：白油使聚乙烯在高温下更易溶胀和混合。其相容性、比例及分散状态会改变熔体是否均匀，并影响冷却后的富油区域。 详见 [[投料与两相体系]]。

- 分子量与链缠结 → 混炼挤出：链越长、缠结越强，通常越难在有限时间内均匀塑化。挤出需要让温度、剪切和停留时间适应该树脂，避免颗粒未溶胀或局部过热。 详见 [[投料与两相体系]]。

- 计量与混合供料 → 熔体与凝胶均匀性：固液配比或瞬时供料变化，会使相邻卷段的树脂与白油比例不同。即使平均配比合格，短周期波动仍可留下混合不均和后续成孔差异。 详见 [[投料与两相体系]]。

- 计量与混合供料 → 黑点与异物：原料、计量输送设备或投料操作带入的颗粒会随物料进入挤出。黑色外观不能区分金属、炭化物和其他污染，须定位并鉴别。 详见 [[投料与两相体系]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
