# 一次分切、边缘与洁净


阶段：基膜。本篇解释通用机制，不包含具体产品配方、设定窗口或现场实测数据。


## 材料发生了什么

分切通过刀具使膜在指定位置断裂。上下刀配合、重叠和安装角度不当，或刀口钝化，会从整齐切断变成拉扯和挤压，留下边毛、撕裂和碎屑。分切张力还会叠加边部变形；带电的膜又容易吸附粉尘。刀具产生的金属碎屑和聚合物边毛应分别识别。


## 由材料变化得到的质量控制点

- 核对刀具安装或连接角度、紧固状态、上下刀配合与重叠量，按磨损状态管理锋利度

- 匹配分切前后张力与纠偏，控制边部受力和接触损伤

- 控制除尘、集屑和静电，检查刀口及辊面异物，不把金属刀屑与普通膜屑混为一类


## 节点与概念

- **分切**：形成目标幅宽并重新分配各分卷受力，需检查边缘与母卷位置。

- **分切边缘损伤**：刀具、切割和边部受力造成或放大的局部损伤，应区别母卷原有缺陷。

- **分切边毛与毛刺**：切割不整齐或刀具碎屑造成的边部异常，聚合物边毛与金属毛刺须分开识别。

- **膜屑与粉尘附着**：切割、设备或环境产生的颗粒附着在膜面，成分和尺寸决定影响。

- **划伤与压印**：接触造成的表面或厚度变化，需区分无损压印与骨架受损划伤。


## 关系机理、控制点与失控问题


### 分切 → 分切边缘损伤

刀具通过局部剪切使薄膜断开。刀口磨损、配合或重叠不当会拉扯边缘，形成边毛、裂口和碎屑。


质量控制点：

- 核对刀具安装或连接角度、紧固状态、上下刀配合与重叠量，按磨损状态管理锋利度

- 匹配分切前后张力与纠偏，控制边部受力和接触损伤

- 控制除尘、集屑和静电，检查刀口及辊面异物，不把金属刀屑与普通膜屑混为一类


控制不好会怎样：边部裂口、边毛和污染可能在后道继续扩大或进入有效覆盖区。


适用时留意：对照母卷对应位置；统一观察方式


如何验证这条路径：比较分切前后边缘；检查刀位与异常分卷关系


### 分切 → 弧度与跑偏倾向

分切各分条受力或边缘损伤不对称时，条带两侧的伸长不同，展开后可能侧向弯曲。母卷已有应力差也会在分切释放后显现。


质量控制点：

- 核对刀具安装或连接角度、紧固状态、上下刀配合与重叠量，按磨损状态管理锋利度

- 匹配分切前后张力与纠偏，控制边部受力和接触损伤

- 控制除尘、集屑和静电，检查刀口及辊面异物，不把金属刀屑与普通膜屑混为一类


控制不好会怎样：条带弯曲或横向轨迹不稳，后道更难维持对齐与边部覆盖。


适用时留意：按规定受力条件测量弧度


如何验证这条路径：比较分切前后自由展开状态；检查各分卷差异


### 分切边缘损伤 → 纵横拉伸性能

边部裂口和损伤会集中拉伸应力，载荷尚未达到主体膜的承载能力时，就可能从切边起裂，降低测得的强度。


质量控制点：

- 核对刀具安装或连接角度、紧固状态、上下刀配合与重叠量，按磨损状态管理锋利度

- 匹配分切前后张力与纠偏，控制边部受力和接触损伤

- 控制除尘、集屑和静电，检查刀口及辊面异物，不把金属刀屑与普通膜屑混为一类


控制不好会怎样：拉断或边部起裂风险上升，走膜稳定性及取样测得的强度可能变差。


适用时留意：确认试样制备和切割边缘


如何验证这条路径：查看断口位置；用合规制样复测


### 分切 → 分切边毛与毛刺

刀口钝化、重叠或安装连接角度不合适、紧固松动，会使切割变成局部拉扯与撕裂，形成边毛、毛刺或刀屑。


质量控制点：

- 核对刀具安装或连接角度、紧固状态、上下刀配合与重叠量，按磨损状态管理锋利度

- 匹配分切前后张力与纠偏，控制边部受力和接触损伤

- 控制除尘、集屑和静电，检查刀口及辊面异物，不把金属刀屑与普通膜屑混为一类


控制不好会怎样：切口不整齐会影响后道边部；金属刀屑另有导电及刺穿风险。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 分切 → 膜屑与粉尘附着

分切产生的膜屑或刀具碎屑，若收集不足或静电较强，会吸附到膜面。颗粒来源要通过成分和形态区分，不能只靠黑点颜色。

控制不好会怎样：粉尘可能被涂层包覆形成凸点，或在电芯压紧时形成局部压点。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。

### 分切 → 前态膜

分切后的基膜把厚度、孔结构、表面、边部和卷内应力一起交给涂覆工序。涂覆前态验收需要继承这些状态及对应卷段，已有涂层中间体要单独识别。


质量控制点：

- 核对刀具安装或连接角度、紧固状态、上下刀配合与重叠量，按磨损状态管理锋利度

- 匹配分切前后张力与纠偏，控制边部受力和接触损伤

- 控制除尘、集屑和静电，检查刀口及辊面异物，不把金属刀屑与普通膜屑混为一类


控制不好会怎样：前态不清或状态不匹配，会把上游缺陷和错误对照带入涂覆分析。


适用时留意：确认实际产品层结构和工序路线，不能把不匹配控制计划拼接。


如何验证这条路径：核验前后卷系谱、方向、层结构与取样位置。


### 分切边缘损伤 → 切边与局部损伤

基膜切边损伤可能被后续涂层覆盖而暂时不明显，也可能在再次分切或张力下扩大。涂覆后边部异常要追溯前态同一位置。


质量控制点：

- 核对刀具安装或连接角度、紧固状态、上下刀配合与重叠量，按磨损状态管理锋利度

- 匹配分切前后张力与纠偏，控制边部受力和接触损伤

- 控制除尘、集屑和静电，检查刀口及辊面异物，不把金属刀屑与普通膜屑混为一类


控制不好会怎样：边裂、缺口、掉粉或折边可能影响走膜对齐和有效覆盖。


适用时留意：卷系谱和切边位置可以确认。


如何验证这条路径：比较各分切工序前后缺陷形态与位置。


### 划伤与压印 → 涂层与基膜界面

划伤或压印会改变局部表面形貌；若伴随污染或涂层接触不足，可能降低结合。只有无污染的浅压印时，作用可能主要是外观。

控制不好会怎样：涂层从基膜表面脱离，湿态或受热后可能失去局部约束。


适用时留意：适用于所述材料状态和实际工序路线；用对应卷段、横向位置与可比正常样确认。


如何验证这条路径：定位实物与前后工序对应位置，比较正常对照并检查机制中的中间变化。


### 分切边毛与毛刺 → 切边与局部损伤

分切边毛和裂口可能在涂布张力下张开或积聚浆料，形成边部不平整和涂层异常，原有边缘损伤也可能继续扩大。

### 膜屑与粉尘附着 → 膜面异物

基膜上的膜屑、粉尘或刀屑进入涂覆后，可能被涂层包住，形成颗粒凸点或黑点。涂覆发现颗粒并不说明颗粒一定在涂覆产生。

### 分切边毛与毛刺 → 局部绝缘薄弱

聚合物边毛可能扰乱对齐或夹入膜层；若同时存在金属刀屑，则还可能导电或刺穿隔膜。两类风险须用实物成分加以区分。

## 还应追溯哪些上游

- 流延成型 → 划伤与压印：模唇积料、辊面硬物或接触受力不均会在软片上留下拉线、划伤或压印。痕迹随拉伸延展后可能改变形态，需按工序映射追溯。 详见 [[铸片冷却与相分离]]。

- 一牵引 → 划伤与压印：脏污或损伤辊面与软膜反复接触，会留下周期压印或划伤。若痕迹节距与辊周长吻合，还需核对中间拉伸和打滑影响。 详见 [[一牵引与含油膜输送]]。

- 收卷 → 划伤与压印：摆辊或其他辊面上的干结硬物会反复挤压膜面，形成周期压印或划伤。辊面清洁、动作状态与实物表面检查需相互对应。 详见 [[收卷、松弛与卷形]]。


## 分析时如何使用

先确认异常位置和实物，再选择上面的具体关系。把正常与异常样的材料状态、卷段、方向和测试条件对齐，观察机理中的中间变化是否存在。只有改善后现象与中间变化一起响应、关联物性复验通过，才逐步提高对该解释的信心。不要把某种外观直接当作化学成分，也不要把一条通用箭头当成这次问题已经确认的根因。
