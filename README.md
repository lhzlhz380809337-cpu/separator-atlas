# Separator Atlas · 隔膜研析

**BUILT & CURATED BY 刘鸿志**<br>
QUALITY · CONTINUOUS IMPROVEMENT · 2026

这是一个保存在本机、可更换模型的隔膜质量分析工作台。第一版覆盖湿法 PE 基膜、陶瓷与聚合物涂覆，以及电芯加工、传输和失效的条件关系。它把通用知识、图谱、诊断步骤和评测题保存在可直接阅读的 Markdown / JSON 文件中。

## 打开使用

日常使用可双击根目录的 **隔膜研析.exe**，程序会隐藏启动本地知识服务，并以无地址栏的独立桌面窗口打开。关闭主窗口后可从 Windows 任务栏托盘再次打开；右键托盘图标选择“退出桌面版”即可结束。也可以双击 **启动桌面版.cmd** 进入同一桌面版本。

浏览器入口为 [start-workbench.ps1](start-workbench.ps1)，运行后打开 `http://127.0.0.1:8765/#home`。保留启动窗口；关闭窗口或按 Ctrl+C 会停止服务。桌面版与浏览器版共用同一套知识、图谱和本地服务，不会生成两份知识库；跨浏览器继续对话时可使用页面中的“保存进度”和“载入进度”。启动失败时窗口会保留提示。此电脑优先使用已具备的 Python，迁移到其他电脑需要 Python 3.10 或更新版本，无需安装第三方库。

完整环境要求、安装检查、端口调整和可选开发依赖见 [环境与依赖](docs/环境与依赖.md)。仓库提供标准的 `requirements.txt`；运行程序不依赖第三方 Python 包。`requirements-dev.txt` 仅用于重新生成桌面图标。

如果默认端口被占用，可在本目录运行 `python app/server.py --port 8766 --open`。网址随端口变化。程序只监听本机，未发布到互联网，也不作为多人共享服务器使用。

1. **星图对话**：首页同时展示知识球和问题对话。默认连接模型，简短推进一个会影响行动的判断；可随时生成系统方案，再继续追问。回复区域优先占屏，单行输入框，对话可拖宽覆盖星球。
2. **知识图谱**：进入即显示基膜、涂覆、电芯的全流程分区总图。点击节点突出直接上下游，右侧依次解释为什么有关联、由此要控制什么、控制不好会怎样。支持阶段筛选、节点搜索、缩放和返回总览。
3. **知识库**：按基膜、涂覆、电芯与分析方法阅读完整专题，搜索术语、指标或异常。四个页面共用深空蓝底色和顶部导航。
4. **模型设置**：保存模型连接，可选配置 Tavily 搜索服务。对话中的“分析材料”可查看并导出本轮完整模型材料；“导出对话”保存问答记录。

“知识投递”文件夹中的通用化 Markdown / TXT 会进入本地星图。正式知识包括 157 个概念节点和 73 篇正文，它们一起形成星球；核心工艺图谱有 294 条条件关系。展开“外部知识”并配置搜索后，真实取得的新来源会以流星飞入，标为当前会话的待核验资料。详细操作见 `docs/星图对话使用说明.md`。

当前对话默认保存在本浏览器，可关闭“本机记忆”。FTA 分析树展示当前路径和保留分支，可从此前问题换一个答案，软删除某个答案及其后续并恢复，也可总结到任一节点。保存进度默认生成可再次载入的 Markdown，正文含完整问答、FTA 分支及删除记录，文件末尾保留程序恢复数据；也可另存 JSON。详细交接记录可手工填写或由模型整理后核对。

0.6.0 新增系统方案、现场行动/深入分析节奏、Windows 加密保存模型连接，以及小屏阅读布局。更新与旧版恢复见 [版本说明](docs/版本说明_0.6.0.md)。保留 0.5.1 的 FTA 能力，将分析树改为可平移、缩放和最大化的横向画布。节点只显示摘要；单击节点会打开详情，显示上一题的选择、本节点问题与选项，并可总结、建立另一条分支或软删除后续。规则与数据契约见 [动态检索与分析进度](docs/动态检索与分析进度.md)。

人工构造的试用问题不对应真实生产事件。首页仅提供模型对话，后端离线规则仍保留供兼容。分析草案不能据此宣称现场根因已经确认。

## 已沉淀的内容

- 73 篇专题：原有 28 篇基础知识，加上独立 `知识图谱/` 文件夹的 45 篇详细机理、缺陷诊断方法与全流程说明。
- 157 个图谱节点、294 条有条件关系，含跨基膜、涂覆及电芯的接口关系。每条关系均有机理、质量控制点、验证方法和失控问题。
- 26 套诊断剧本，覆盖原有物性问题以及黑点、亮点、厚度不均、条纹、缩孔、损伤、皱折、粘连、开裂、脱层和点涂异常。
- 18 个人工构造的评测问题，包含错误前提、路线混用、信息不足和泄露指令。
- 公开文献与方法来源及其适用范围。部分研究只核验了公开摘要，已在来源索引中说明。

知识正文约 16.6 万字符，另含图谱、剧本和智能体规则；部分控制点会在相关章节重复出现，以便模型独立读取片段。这里的数量用于描述覆盖，不能代表科学验证程度或模型准确率。

## 文件怎么组织

| 位置 | 用途 |
|---|---|
| `knowledge/base/` | 材料、相分离、成型、拉伸、萃取、热定型、后处理、结构物性 |
| `knowledge/coating/` | 涂层、浆料、涂布、干燥、界面、洁净、电芯加工与性能 |
| `knowledge/foundation/` | 全流程、术语、公式及测量边界、缺陷定位、控制反应 |
| `knowledge/methods/` | 测量、分层、统计、因果、试验、PFMEA、知识治理 |
| `知识图谱/` | 全流程与详细关系的 Markdown，和基础知识一起进入星图、检索与导出 |
| `graph/` | 节点和作用关系；机理、控制点、失控问题、适用条件与验证 |
| `agent/` | 系统提示词、分析与对话协议、补查协议、诊断剧本 |
| `evals/` | 人工构造的测试题与验收准则 |
| `docs/` | 模型接入、知识维护、资料需求与验证说明 |
| `app/` | 本地程序与界面 |
| `requirements.txt` | 运行环境声明；当前无第三方运行依赖 |
| `requirements-dev.txt` | 可选开发依赖；普通使用无需安装 |
| `exports/` | 发布工具生成的独立程序包及知识包 |

原始资料目录不属于程序知识库。程序不会读取、网页展示、检索或打包原始资料。请通过“导出知识包”或 `exports/` 的发布包迁移，**不要把包含原始资料的整个工作文件夹直接分享**。

## 模型接入

支持 OpenAI 兼容 Chat Completions 和 OpenAI Responses 两种文本接口。输入服务商给出的地址、模型名和密钥，点击“保存连接”，再测试连接。Windows 使用当前用户范围 DPAPI 加密密钥，保存于 `%LOCALAPPDATA%/SeparatorAtlas/settings.local.json`，重开浏览器或桌面版均可沿用。密钥不会回传前端，也不进入 Git、会话或知识包。更换服务目的地址时不沿用原密钥。

调用前先检查当前问题和材料包，只使用已获准的通用化输入。发送确认针对所填模型服务，更换地址或模型后需要重新确认。程序对常见联系方式、文件路径、文件名及敏感字段作发送前检查，但无法识别所有内部代码、配方或可识别的数据组合。

没有密钥仍可使用全部本地知识功能。迁移与详细限制见 `docs/模型接入与迁移.md`。本次没有使用真实服务密钥，不能声称所有服务商和模型已经实测兼容。

## 检查与维护

在本目录运行：

```text
python -m unittest discover -s tests -v
python tools/validate.py
python tools/evaluate.py
python tools/release.py
```

前三项分别检查程序、知识结构和本地检索回归。最后一项按明确清单生成发布包。它们不代替专业评审或模型实际答案评测。知识变更后，先校验，再刷新页面中的知识；发布清单应通过发布工具更新。

## 当前边界

这是一套可以使用并持续扩充的知识工作台，不能称为已覆盖所有产品、所有失效或全部现场经验。它没有连接产线、MES、实时数据或企业知识平台。只有明确开启并配置搜索时才会查询公开资料；不会自动把对话写成正式知识、修改控制计划、调机或放行。

知识和步骤能降低模型遗漏、混淆和无依据猜测，但不能保证较弱模型达到更强模型的分析水平。实际能力需通过合成题、专业盲评和经授权的通用化问题逐步评价。

## 案例规范与版本保存

后续知识按初始知识、知识图谱、现场经验教训、优秀专项、客诉 FTA 五类组织。案例整理和关联规则见：

- [案例报告转 Markdown 入库规范](正式案例库/_01_案例报告转Markdown入库规范.md)：三类模板、脱敏、证据状态、转换流程与审核要求。
- [五类知识关联与图谱维护规范](正式案例库/_02_五类知识关联与图谱维护规范.md)：关系机理、适用条件、证据关联、FTA 逻辑及后续接入约定。

`正式案例库/` 目前尚未接入自动加载，两份规范已区分现有能力和后续规划。日常自建知识仍通过 `知识投递/` 加载。

Git 仓库保存程序、通用知识、测试和维护规范。公司原始资料、自建笔记、实际案例、运行配置、密钥、日志及生成的导出包默认不纳入版本；正式案例库目前仅纳入上述两份规范。新增资料前先核对分享范围，不因仓库设为私有就自动将原始材料加入。
